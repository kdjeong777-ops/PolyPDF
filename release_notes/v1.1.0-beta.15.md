#### 이번 판에서 달라진 점
- **설정 폴더 이사 보완** — PolyPinax 로 이사할 때 설정 폴더를 옮기지 못하면(다른 프로그램이 파일을 쓰고 있을 때) 몇 번 더 해 보고, 그래도 안 되면 다음 실행 때 다시 옮깁니다. 그동안에는 전에 쓰던 설정을 그대로 씁니다.
- **옛 바로가기 고침** — 시작 메뉴·바탕 화면·작업 표시줄에 남은 PolyPDF 바로가기가 새 PolyPinax 실행 파일을 가리키도록 저절로 고쳐집니다.

#### 이렇게 써 보세요
- 업데이트 뒤 작업 표시줄이나 시작 메뉴에 고정해 둔 옛 아이콘을 눌러 보세요. PolyPinax 가 열립니다.
- 환경설정·즐겨찾기·최근 파일이 전처럼 그대로인지 확인해 보세요.

#### What's new
- **Settings folder move, improved** — If the settings folder can't be moved to PolyPinax (because another program is using its files), the app retries a few times and tries again on the next start. Until then it keeps using your existing settings.
- **Old shortcuts fixed** — Leftover PolyPDF shortcuts in the Start menu, on the desktop and on the taskbar are updated automatically to open the new PolyPinax executable.

#### Try it
- After updating, click an old pinned icon on the taskbar or in the Start menu. PolyPinax opens.
- Check that your settings, favorites and recent files are all still there.
