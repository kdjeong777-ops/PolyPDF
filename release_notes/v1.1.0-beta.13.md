#### 이번 판에서 달라진 점
- **새 이름 PolyPinax** — 프로그램 이름이 PolyPinax 로 바뀌었습니다. PDF 모드는 PolyPDF, 사진 모드는 PolyPix 입니다. 설정·색인·기본 앱 등록은 그대로 이어집니다.
- **해시태그 수정 창** — 왼쪽 '붙일 수 있는 태그'(문서 종류·자동 해시태그 속성·기존 태그·후보), 오른쪽 '붙은 태그'의 두 목록으로 바뀌었습니다. 두 번 누르거나 끌어서 붙이고 뗍니다. 여러 파일 중 일부에만 붙은 태그는 ◐ 로 보입니다.
- **자동 해시태그 (PDF 모드)** — 날짜·한글·영어·스캔문서·텍스트문서·스크린샷과 제품설명서·영수증·공문·견적서·보고서·발표자료·논문을 스스로 붙입니다. 2단 편집 설명서·옆으로 긴 쪽 판정을 다듬고, 잘못 붙은 종류는 한 번에 바꿀 수 있습니다.
- **더 빠른 태그 계산** — 색인할 때 태그 재료를 함께 뽑아 태그 계산이 크게 빨라졌고, 색인 중에도 문서 종류가 먼저 붙습니다. 계산 중에는 작업 창에 진행이 보입니다.
- **책갈피창 빠른 훑기** — '책갈피 모두 접기' 상태에서 ↑↓ 로 파일을 옮기면 책갈피를 펼치지 않고 표지부터 빠르게 보여 줍니다. 배경 그림이 아주 많은 PDF 도 끊기지 않게 열립니다.
- **기본 앱 설정 한 번에** — 환경설정 '보기 종류'(기본: 혼용) 옆 [기본 앱 설정] 으로 PDF 와 사진 기본 앱을 이어서 고릅니다.

#### 이렇게 써 보세요
- 책갈피창에서 파일 여러 개를 고르고 '#' ▸ 해시태그 수정 — 왼쪽의 '제품설명서' 를 두 번 누르면 고른 파일에 붙습니다.
- 책갈피창 PDF 우클릭 ▸ 문서 종류 ▸ 원하는 종류 — 잘못 붙은 종류를 바로 고칩니다.
- '#' 메뉴에서 형식·속성을 하나 고르면 그 종류만 걸러 봅니다(다시 누르면 풀림).
- 우클릭 ▸ 책갈피 모두 접기 를 켜고 ↑↓ 로 표지를 넘겨 보세요. Enter·→ 로 그 파일 책갈피를 펼칩니다.
- 도구 ▸ 설치·설정 ▸ 기본 앱 설정 — 보기 종류대로 PDF·사진 기본 앱을 고릅니다.

#### What's new
- **New name: PolyPinax** — The program is now called PolyPinax. PDF mode is PolyPDF and photo mode is PolyPix. Your settings, index and default-app registrations carry over.
- **Modify Hashtags window** — Two lists: 'Tags you can add' (document types, automatic hashtag attributes, existing tags, candidates) on the left and 'Tags on files' on the right. Double-click or drag to add or remove. Tags on only some of the selected files show as ◐.
- **Automatic hashtags (PDF mode)** — Date, Korean, English, scanned, text, screenshot, plus product manual (제품설명서), receipt, official letter, quotation, report, presentation and paper are added automatically. Detection of two-column manuals and wide pages is improved, and a wrong document type can be fixed in one step.
- **Faster tag calculation** — Tag material is collected while indexing, so tagging is much faster and document types appear while indexing is still running. Progress shows in the Tasks window.
- **Quick browsing in the bookmark pane** — With 'Collapse All Bookmarks' on, moving with ↑↓ shows each file's cover quickly without expanding its bookmarks. PDFs with very many background images open without stalling.
- **Default apps in one place** — The [Set Default Apps] button next to Settings 'View type' (default: Mixed) sets PDF and photo default apps in turn.

#### Try it
- Select several files in the bookmark pane, then '#' ▸ Modify Hashtags — double-click '제품설명서' (product manual) on the left to add it to the selected files.
- Right-click a PDF in the bookmark pane ▸ Document type ▸ choose a type to fix a wrong one.
- In the '#' menu, pick one type or attribute to filter by it (click again to clear).
- Turn on right-click ▸ Collapse All Bookmarks and browse covers with ↑↓; press Enter or → to expand that file.
- Tools ▸ Install & Setup ▸ Set Default Apps — choose PDF and photo default apps for your view type.
