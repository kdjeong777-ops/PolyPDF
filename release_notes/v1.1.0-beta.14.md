#### What's new
- **Moved to PolyPinax** — The executable, install folder (`Program Files\PolyPinax`), settings folder and taskbar name are now PolyPinax. Your settings, index, favorites, PDF passwords and default-app registrations move over unchanged.
- **New GitHub repository** — From this version, updates and source code come from the new repository kdjeong777-ops/PolyPinax. The old repository is archived.
- **Fewer prompts when signing** — If the only thing not yet written into the PDF is automatically added hashtags, signing goes ahead without asking to save first.

#### Try it
- After updating, start PolyPinax from the Start menu or taskbar. Your folders and favorites are still there.
- Check the new source code address in Help ▸ About.
- Double-click a PDF — your default PDF app setting carries over.
