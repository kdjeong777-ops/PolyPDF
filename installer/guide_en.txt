PolyPDF — Getting Started
====================================================

[ Basic use ]
Viewing and editing PDFs, bookmarks, search, screenshots, reading aloud
and screen recording all work right away — no sign-up or setup needed.

[ Setting PolyPDF as the default PDF app ]
If you checked 'Set PolyPDF as the default PDF app' during setup, the Windows
'Default apps' settings open after installation. Choose  .pdf  →  PolyPDF  there.
   * For security, Windows 10/11 makes you confirm the final choice yourself,
     so the installer does not change the default app automatically (this is normal).
   * You can also right-click a PDF file → 'Open with' → PolyPDF.

[ Language ]
Menus, dialogs and help follow the language you chose during setup.
You can change it later in the 'Language' group at the top of Tools → Settings (applied after a restart).

[ Updates ]
Help → 'Check for Updates'. If a new version is available, it shows what changed,
downloads the update first, then closes PolyPDF and installs it.

[ Sound in screen recordings ]
If you need sound in recordings, check your audio devices first with
Tools → Settings → 'Test Recording'.
