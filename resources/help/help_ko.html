PolyPDF 사용법

1. 시작하기

  • 파일 → 폴더 열기 (Ctrl+O) — PDF 들이 들어있는 폴더 선택. 폴더에 bookmarks.json 이 있으면 책갈피 트리로, 없으면 모든 PDF 가 평면 트리로 표시됩니다.
  • 파일 → 파일 열기 (Ctrl+Shift+O) — 단일 PDF 만 열기. 즐겨찾기 → 최근 폴더 / 최근 파일 로 전에 연 것을 다시 엽니다.
  • PDF 파일이나 폴더를 창에 드래그&드롭 해도 동일하게 열립니다.
  • 탐색기에서 PDF 여러 개를 한꺼번에 열면 한 창에 모이고, 그 뒤에 따로 열면 새 창으로 열립니다.
  • 처음 폴더를 열면 백그라운드에서 텍스트 인덱싱이 진행됩니다(상태바 진행률). 색인이 어긋나면 도구 → 인덱스 재구축.
  • 편집 모드 / 보기 모드: 책갈피창 위 편집 단추로 바꿉니다(파란 연필 = 보기, 빨간 연필 = 편집). 처음 모드는 환경설정 '시작 시 동작' 의 PolyPDF 시작 모드.
  • 도구 → 등록·설치 → 기본 PDF 앱 등록…: PolyPDF 를 '연결 프로그램' 목록에 올립니다 (기본 앱으로 고르는 것은 Windows 설정에서 — 창이 방법을 안내합니다).

2. 화면 구성

  • 좌1 책갈피창: 클릭 → 메인 뷰어 로드. 파일 노드의 갈매기(▸)를 펼치면 PDF 내부 책갈피(TOC)가 표시됩니다. 위쪽에 목록 명칭 검색 칸 · #(해시태그, §14) · 정렬(§8) · 📁 폴더(파일 모드 ↔ 폴더 모드) · 트리(단일 ↔ 트리) · ↻(밖에서 파일이 바뀌었을 때 새로고침 — 편집 모드에서도, 저장 안 한 수정이 있으면 먼저 묻습니다).
  • 파일·책갈피 오른쪽 클릭: 파일 탐색기 열기 · 새 폴더 만들기 · 파일·책갈피 이름 변경 · 파일·책갈피 삭제 / 저장 · 다른 이름으로 저장 · 평탄화해서 내보내기 / 2단 보기 · 책갈피 모두 펼치기·접기 / 책갈피 생성 · 해시태그 편집 · 즐겨찾기에 추가 등. 편집 모드에서는 파일 복사·이동(새 폴더 만들기 아래), 폴더 이름 변경·삭제, 여러 파일 병합도 있습니다.
  • 책갈피 모두 펼치기(우클릭): 책갈피 창에 보이는 파일들의 책갈피를 모두 펼칩니다. 켜져 있는 동안(메뉴에 체크) 스크롤하거나 목록이 바뀌어 새로 보이는 파일도 펼칩니다. 책갈피 모두 접기: 그 상태를 끄고 파일 줄까지 접어 목록에 파일만 남깁니다.
  • 좌2 페이지 썸네일: 현재 PDF 의 전 페이지. 클릭 → 점프. 위쪽 단추로 거르기: 전체 · 보임(숨기지 않은 쪽) · 꾸밈(선·도형·글·사진이 있는 쪽) · 숨김. 썸네일 오른쪽 클릭 → '책갈피 추가'(현재 트리 파일에) · 인쇄 · 스크린샷으로 복사 · 쪽 편집(§10).
  • 중앙 메인 뷰어: 상단 툴바 = ‹ [페이지] /N › · 줌 −/+ · 화면캡쳐 · 본문 읽기 ▶ + 재생구간 ▾ · mp3 · 보기 콤보(쪽/2장/폭/사용자 비율). 편집 모드에서는 꾸밈 도구(§9)가 이어 붙습니다. 우측 세로 스크롤바는 문서 전체 진행률(끌어서 이동). 본문 오른쪽 클릭(또는 Shift+F10): 인쇄…(인쇄 창, 현재 페이지) · 복사(지금 쪽) · 텍스트 복사 · 블럭설정 후 텍스트 복사 · 2단 보기(2단이면 1단 보기 · 옆 창에 열기) · 발표보기 · 90° 회전 · 여기에 서명…. 편집 모드에서는 붙여넣기 · 스크린샷 붙여넣기 · 클립보드 붙여넣기 · 사진 붙여넣기 · 삭제 · 저장 · 숨김/숨김 해제 · 책갈피 추가 · 하이퍼링크 등록 · 도형/글쓰기 입력 설정도. 편집 모드에서 개체를 고르지 않고 Del 을 누르면 지금 쪽을 지웁니다(저장 전). 메뉴 오른쪽에는 그 항목의 단축키가 보입니다. 붙여넣기는 마지막에 복사한 것을 붙입니다 — 쪽을 복사했으면 지금 쪽 아래에 쪽, 개체를 복사했으면 누른 자리에 개체. 클립보드 붙여넣기는 쪽·그림이면 그림으로, 글이면 글쓰기 박스로 붙입니다.
  • 메뉴 탭: 창 맨 위 모음 · 파일 · 즐겨찾기 · 보기 · 도구 · 도움말 탭을 누르면 고른 탭 아래에 그 항목이 한 줄로 나옵니다(Alt+F·V·B·T·H 로도 탭을 바꿉니다). 모음은 자주 쓰는 단추를 모은 탭으로 시작할 때 늘 보이고, 환경설정이나 탭 줄 우클릭의 모음 메뉴 관리... 에서 넣고 빼거나 차례를 바꿉니다(Alt+C 로 모음 탭). 탭 줄 우클릭 리본 메뉴 보이기 를 끄면 탭을 누를 때만 잠깐 보입니다. 검색창은 탭 줄 오른쪽 끝에 있습니다.
  • 보기 단추(모음 · 보기 탭): 1단(오른쪽 패널 숨김) · 2단 · 텍스트 · 단어장 · 검색 · 스크린샷 · 발표보기(§13).
  • 2단 보기(Ctrl+Shift+2): 메인 뷰어를 좌·우 두 창으로 나눠 두 PDF를 동시에 봅니다. 창을 클릭하면 그 창이 활성(파란 테두리)이 되어 책갈피·검색·썸네일·읽기·단어장이 활성 창을 대상으로 동작하고, 각 창의 📷 캡쳐·읽기·mp3 버튼으로 그 창을 따로 처리합니다. 우클릭 '옆 창에 열기' 로 다른 창에 같은 문서·쪽을 엽니다. 한 창에서 저장해도 다른 창은 보던 파일·쪽 그대로입니다.
  • 패널 슬라이드: 2단이거나 검색·스크린샷을 둘 다 숨기면 오른쪽 패널이 슬라이드 드로어로 들어가, 가장자리 핸들(‹)로 펼쳐 쓸 수 있습니다 (캡쳐 시 잠깐 펼쳐졌다 1.5초 후 접힘). 스크린샷만 켜면 그리드로 펼쳐 표시됩니다.
  • 오른쪽 패널: 위 = 📄 텍스트 · 📖 단어장 · 🔎 검색 탭, 아래 = 스크린샷. 스크린샷은 모두 삭제되면 창이 자동 숨김.

2-1. 본문 읽기 (TTS) · mp3

  • 툴바 ▶ = 현재 페이지부터 본문 읽기/정지(머리말·표·수식·그림 제외). 읽는 문장이 옅은 파랑으로 표시되고 페이지를 자동으로 따라갑니다. 문장을 클릭하면 그 문장부터 다시 읽습니다.
  • 재생구간 ▾: 1회 / 연속 / 전체 / 전체연속, 빠르기(느림·보통·빠름·매우 빠름)·성우(자동은 언어별, 단어장과 공유).
  • 툴바 mp3(MP3 아이콘): 현재 PDF를 책갈피 위계(1/2/3) 기준으로 분할 하여 구간별 mp3(+가사 .lrc)로 저장(책갈피 없으면 전체 1개).

2-2. 페이지 넘기기 (휠·트랙패드·키보드)

  • 휠: 확대한 쪽은 쪽 안에서 먼저 움직이고, 끝에 닿으면 조금 더 굴려야 다음 쪽으로 넘어갑니다. 쪽 맞춤에서는 한 칸 = 한 쪽. 트랙패드의 관성으로는 쪽이 넘어가지 않습니다. Ctrl+휠 = 줌.
  • 페이지 이동 방식(환경설정): 한 쪽씩(기본, '쪽 넘김 애니메이션' 켜고 끄기) / 이어 보기(앞뒤 쪽을 붙여 조금씩 스크롤 — 화면 가운데 쪽이 현재 쪽). 2장 보기와 스크린샷 보기는 늘 한 쪽씩.
  • 가벼운 넘김(환경설정, 기본 자동): Windows 전원 모드가 '최고의 전력 효율'·배터리 절약이거나 쪽 넘김이 느리면 저절로 켜져 상태 표시줄에 🔋 가벼운 넘김 이 보입니다. 넘김 애니메이션을 끄고, 잇달아 넘기면 가운데 쪽은 건너뛰며, 텍스트 창은 넘김이 멈춘 뒤 따라가고, 다음 쪽을 미리 그려 둡니다. 이때 OCR·단어장 생성·번역 같은 무거운 작업을 시작하면 오래 걸릴 수 있다고 알려 줍니다.
  • 마지막/첫 페이지에서 다음·이전 파일로 이동(환경설정, 기본 켜짐): 끝에서 더 넘기면 다음(이전) PDF 의 첫(마지막) 쪽 미리보기와 함께 볼지 묻습니다. 책갈피창에서 고를 때는 묻지 않습니다.
  • 키보드: PgUp/PgDn 한 쪽 · ↑/↓/Space(Shift+Space 뒤로) 쪽 안에서 먼저 움직인 뒤 다음 쪽 · Home/End 첫/마지막 쪽 · Ctrl+C 텍스트 복사.

3. 검색

  • 우상단 검색바에 검색어 → Enter. 매치는 본문에 형광색으로 표시됩니다. 검색칸 옆 Aa = 대소문자 구분, .* = 정규식(예: \d{4}-\d{2}) — 결과 목록·본문 강조·F3 이동이 모두 같은 규칙입니다.
  • 검색은 빈칸·줄바꿈을 무시합니다 — 줄 끝에서 끊긴 말('아스팔트⏎포장')이나 띄어쓰기를 달리 친 말('아스팔트포장')도 찾습니다. 스캔본은 OCR 결과를 저장하면 그 글로 찾습니다(저장 뒤 그 파일을 다시 색인).
  • 결과 정렬: 책갈피 순 / 이름 순 / 횟수 순.
  • F3 / Shift+F3 또는 검색바 ▶ / ◀: 다음 / 이전 매치. 파일 안 마지막 매치 다음을 누르면 결과의 다음 파일 첫 매치로 점프.
  • #태그로 거르기: 책갈피창 # 단추에서 태그를 고르면 검색어에 #태그 가 들어갑니다(§14).
  • 저장: 결과를 엑셀(.xlsx)로 (파일명 날짜·시각 접두 자동).
  • 전체 캡쳐: 검색 결과의 모든 매치 페이지를 일괄 스크린샷. 결과 수가 한도를 넘으면 한도가 자동 확장됩니다.
  • 자주 쓰는 검색어는 즐겨찾기 → 현재 검색어 추가.

4. 스크린샷 / 화면 캡쳐

  • 메인 툴바의 📷 캡쳐 또는 Ctrl+Shift+S 로 캡처. 캡쳐 아이콘 오른쪽 드롭다운에서 모드 선택: 전체화면(현재 페이지/선택 썸네일) · 영역 캡처(화면에서 누른 채 끌어 영역을 고른 뒤 끌기·화살표로 옮기거나 크기를 고치고 Enter 또는 더블클릭으로 캡처 · 오른쪽 클릭은 다시 고르기 · 시작할 때 Enter 는 지난 영역) · 사용자 크기1~5 (클릭 지점에 지정 크기 박스, 크기는 '사용자 크기 설정'에서 이름·픽셀 지정·저장). 캡쳐 화질 설정(보이는 화질/원본 화질). 단축키 설정에서 화면 캡처를 전역 단축키(다른 프로그램 위에서도)로 쓸 수 있습니다.
  • 썸네일 여러 개 선택 후 캡쳐하면 각 페이지가 전체화면으로 일괄 저장됩니다 (썸네일 우클릭 '스크린샷으로 복사' 도 같음).
  • 스크린샷 카드 아래에 순서 번호가 표시됩니다(재정렬·삭제 시 갱신). 카드는 끌어서 순서를 바꾸고, 우클릭 '삭제'(여럿 고르면 '선택 n개 삭제') · 🗑 전체 삭제. 편집 모드에서 카드를 썸네일로 끌어 놓으면 그 자리에 새 쪽으로 들어갑니다.
  • 클립보드로 복사(📋, Ctrl+Shift+C): 스크린샷들을 순서대로 클립보드에 복사 → Win+V 목록에서 차례로 붙여넣기.
  • 클립보드 가져오기(📥): 클립보드의 그림(캡처 도구로 복사한 그림, 탐색기에서 복사한 그림 파일)을 스크린샷 카드로 넣습니다.
  • 2장 보기에서는 좌·우 페이지가 각각 카드로 저장됩니다.
  • 스크린샷 카드 클릭 → 메인에 표시. 캡처 당시 검색어가 있었다면 원본 페이지를 형광펜과 함께 다시 렌더해 보여줍니다.
  • 표시 중 ◀ ▶ · 페이지번호 입력 · 우측 스크롤바 · 휠로 스크린샷 리스트 전체를 이동할 수 있고, 보기 콤보로 쪽/폭/사용자 비율 전환(기본 쪽 맞춤).
  • 💾 PDF 저장 또는 Ctrl+Alt+S: 누적 스크린샷을 한 PDF 로 저장. 옵션 대화상자에서 ① 검색어 형광펜 표시(켜면 고해상도 재렌더, 끄면 원본 1:1) ② 상단 파일명 ③ 하단 페이지번호 를 선택. 선택값은 다음 저장 기본값이 됩니다. 저장한 뒤 이 창에 불러올지 묻습니다.
  • 스크린샷 리스트는 시작할 때 늘 비어 있고, 종료할 때 목록이 있으면 PDF 로 저장할지 묻습니다.

5. 한국어 전용 기능 — 단어장 · 번역 · 법령·건설기준·특허

화면 언어가 한국어일 때만 보입니다(다른 언어에서는 메뉴·단추가 숨겨지고 데이터는 그대로 남습니다).

  • 단어장 생성(툴바 · 도구 → 단어장 생성 (OCR·어휘)... · 파일 우클릭): 현재 PDF를 OCR·분석해 페이지별 학습 단어(난이도·한글뜻· 영어뜻·예문)를 만듭니다(1회). 스캔/이미지 PDF도 OCR로 처리. 단어장·책갈피 동시 생성... 도 있습니다.
  • 단어장 탭(오른쪽 패널 📖): 종류(초/중/고)·정렬·표시(한/영/예) 필터, 단어 클릭 → 본문 위치 강조. 읽기 ▶/■ + 재생구간/재생내용(한·영·예), 선택 단어 날짜별 ▲저장/▼삭제. Word 아이콘 = 전체 단어를 Word(.docx)로, MP3 아이콘 = 재생 내용을 페이지별 mp3(+가사)로 저장.
  • 📖 사전 및 용어집 관리(도구 메뉴): 단어장 관리(출처·우선순위·폴더) · 용어집 가져오기(PDF·CSV) · 사전 백업·복원 · 사전 내보내기(TBX·CSV) · 인터넷 사전 보강 등. 환경설정 인터넷 사전 (단어장) 에 표준국어대사전·온용어 키를 넣으면 온라인 조회.
  • PDF번역(툴바 · 도구 → PDF번역 · 책갈피창 우클릭 '번역...' / 여러 파일 '선택 n개 파일 번역...'): 영어 PDF 를 한국어로 번역해 Word·PDF 로 저장합니다(용어집 우선). '번역 용어집 교정...' 으로 용어를 고칩니다. 환경설정 번역 (Claude) 에서 API 키 또는 Claude 로그인을 정하고, 본문이 Anthropic(Claude) 서버로 전송됨에 동의해야 합니다.
  • 법령·고시(법제처) · 건설기준(KCSC) · 특허(KIPO)(도구 → 🔍 검색 및 데이터 구축 · 보기 메뉴): 검색과 본문 보기. 환경설정 인터넷 사전 (단어장) 에 법제처 OC · KCSC 키 · KIPRIS 키를 넣어야 쓸 수 있습니다(키가 없으면 단추 숨김·메뉴 꺼짐). 즐겨찾기 메뉴에 법령·KCSC·KIPO 구역이 생깁니다.

6. 책갈피 자동 생성 (도구 → 책갈피 자동 생성... / 파일 우클릭 '책갈피 생성')

  • 현재 PDF(또는 트리에서 우클릭한 파일)를 분석해 책갈피를 만듭니다.
  • 모드: 자동(목차 있으면 TOC, 없으면 폰트, 스캔 이미지면 OCR 자동) · TOC 강제 · 폰트 강제 · 스캔/이미지(OCR). OCR 모드는 스캔본의 'CHAPTER 1'·'제1장' 등을 인식하며, '큰 글자도 헤딩으로 포함' 옵션 제공.
  • 같은 페이지에 책갈피가 여럿 생기면 제목명(제1장·CHAPTER 1)·번호(1·1.1)만 남기고 잡음을 제거합니다.
  • 스캔본도 목차 쪽을 찾아(앞 15쪽) 목차대로 만듭니다. 이미 OCR 한 쪽(텍스트 창 'OCR 다시 읽기'·단어장)은 다시 읽지 않고, 새로 읽은 쪽은 텍스트 창에 바로 보입니다.
  • 결과: PDF 에 바로 쓰지 않습니다 — 책갈피창의 그 파일에 저장하지 않은 상태로 들어가고(편집 모드), 확인한 뒤 [저장]을 눌러야 PDF 에 씁니다. 알PDF용 .txt는 고르면 바로 만듭니다.
  • 검토 표: Del = 선택 행 삭제, [제목 수정] = 지금 행 제목 고치기, [확인] = 책갈피창에 넣기.
  • 오래 걸리면 아래 상태 표시줄의 진행 바를 눌러 '작업' 창에서 [중지]할 수 있습니다. 읽은 쪽은 남아 다시 만들면 이어서 하고, 중지 창에서 지금까지 찾은 것으로 검토 표를 열거나 OCR 결과까지 버릴 수 있습니다.
  • OCR·단어장 결과도 [저장]해야 남습니다 — 상태 표시줄 '💾 저장 안 한 OCR' 단추나 책갈피창 [저장], 종료 때 묻는 창에서 저장합니다.

7. 책갈피 편집 (책갈피창 위 [편집])

  • 편집(연필 아이콘)을 켜면 취소(저장 전 수정 모두 되돌리기)·저장 과 편집 단추 두 줄이 나타납니다. 편집 중 책갈피를 클릭하면 그 위치로 메인이 이동하고, 더블클릭하면 편집 창이 열립니다. 항목 우클릭 → 파일·책갈피 이름 변경 / 파일·책갈피 삭제 / 책갈피 수정... / 선택 책갈피 페이지순 정렬. 책갈피를 바꾸는 일(이름 변경·삭제·추가·자동 생성)은 편집 모드에서만 됩니다 — 보기 모드면 편집 모드를 켤지 묻습니다(파일 이름 변경·삭제는 언제나). 2단 보기에서는 만든 책갈피가 그 책갈피창에 들어가고, 두 창에 같은 파일이 있으면 두 창 모두 같게 바뀝니다.
  • ◀ / ▶: 내어쓰기 / 들여쓰기. ▲ / ▼: 위/아래 이동. 마우스 드래그로도 이동.
  • 🗑️ 삭제(책갈피=트리 제거 · 파일=휴지통), Shift + 🗑️ 삭제(선택한 책갈피만 남기고 그 파일의 나머지 책갈피 삭제, 확인 뒤), 📋 복사(선택 파일을 다른 폴더로 복사), 💾 저장(<원본>_edited.pdf). 뷰어 화면 우클릭으로도 현재 페이지 책갈피를 추가할 수 있습니다.
  • 변경한 내용이 있는 채로 편집을 끄면 저장 / 되돌리기(저장 안 함) / 계속 편집 을 묻습니다.

8. 책갈피 트리 정렬

  • 검색바 아래 정렬 콤보: 책갈피 순(기본) · 이름 순 · 수정일 순 · 크기 순.
  • bookmarks.json 이 있으면 그 순서를 따르고, 평탄(폴더-PDF) 모드에서만 콤보가 즉시 재정렬합니다.

9. 꾸밈 — 선·도형·글·사진·하이퍼링크 (편집 모드)

  • 편집 모드에서 쪽 툴바에 꾸밈 도구가 붙습니다. 선 1~5(Ctrl+1~5, 색·굵기·투명도) · 선긋기(더블클릭: 직선 / 하이라이트 / 자유곡선, Ctrl+`) · 도형(사각형 / 둥근 사각형 / 원형, ▾ 채움 없음·반투명 채움·채움) · 글쓰기(글상자 ↔ 지시선 글쓰기, ▾ 스타일: 본문·제목·메모·강조) · 개체 선택(이동·크기·삭제, 범위로 여럿) · 지우개(얇게 Ctrl+E / 두껍게 Ctrl+Shift+E) · 청소(현재 쪽 선 모두, Ctrl+Shift+Backspace) · ↶ 되돌리기(Ctrl+Z) / ↷ 다시실행(Ctrl+Y) — 편집 모드에서 한 일(꾸밈·사진·책갈피·쪽 이동·삭제·나누기·숨김·회전·하이퍼링크·크롭)을 한 일 차례대로 되돌립니다(창 어디서나, 쪽을 넘겨도).
  • 글을 쓰는 동안 ▲▼ 로 글자 크기, ◀▶ 로 자간을 바꿉니다. 선택한 개체는 화살표(Shift = 1px)로 옮기고 Del 로 지웁니다.
  • 고른 개체의 우클릭: 글상자·선·사진을 고르면 우클릭 메뉴에 그 개체의 옵션만 보입니다(글상자의 '선과 텍스트 입력 설정…' 은 글쓰기 탭으로 열림). 크롭·전자서명 단추는 편집 모드에서만 보입니다.
  • 복사·붙여넣기: 선택한 글상자·선·도형·사진(범위로 고른 여럿도)을 Ctrl+C → Ctrl+V(같은 쪽은 조금 비켜, 다른 쪽·다른 파일은 같은 자리). 우클릭 '복사'·'붙여넣기' 는 누른 자리에 붙입니다. Shift 를 누른 채 끌면 원본은 두고 복사본이 옮겨집니다.
  • 본문 우클릭 도형 입력 설정… / 글쓰기 입력 설정…: 선 1~5·하이라이트 투명도·지우개 크기, 글쓰기 스타일(글꼴·크기·색·자간· 상자선·배경·정렬·지시선 끝모양)을 정하고 저장합니다.
  • 사진: 우클릭 '사진 붙여넣기' · '클립보드 붙여넣기'(▼ 사각형/둥근 사각형/원형) · '스크린샷 붙여넣기'(고른 스크린샷, 없으면 전부), Ctrl+V, 그림 파일 끌어 놓기. 선택한 사진은 Ctrl+↑/↓ 로 투명도.
  • 하이퍼링크 등록…(본문·썸네일 우클릭): 명칭과 함께 파일(책갈피 폴더 안의 문서·이미지·동영상 등) 또는 외부 링크(URL)(https, 허용 도메인)를 등록하면 쪽 위에 파란 단추로 보입니다. 실행 파일은 막습니다. 다단 인쇄·내보내기에도 따라갑니다.
  • 저장(💾) = 책갈피·쪽 편집·회전·크롭은 원본 PDF 에 넣고, 꾸밈(선·도형·글·사진)·하이퍼링크·태그도 다른 PDF 뷰어에서 보이게 PDF 에 함께 넣습니다 ('PolyPDF' 레이어 — 다른 뷰어의 레이어 창에서 끌 수 있음). 고칠 때는 PolyPDF 에서 그대로 고치고 다시 저장하면 됩니다. 서명된 문서에는 꾸밈 사본을 넣지 않습니다 · 다른 이름으로 저장... · 평탄화해서 내보내기... = 꾸밈·사진·하이퍼링크를 쪽 내용으로 굽고 크롭 바깥 내용을 실제로 지운 새 파일(_평탄화.pdf, 글자 검색은 그대로, 원본은 그대로). 주석을 무시하는 프로그램·제출용·가린 내용을 없애야 할 때 씁니다. 서명된 문서는 같은 자리에 다시 서명합니다(디지털 ID 확인 — 취소하면 그 서명은 빼고 내보냄).
  • 저장하려는 파일을 다른 PolyPDF 창이 열고 있으면 닫고 저장 / 새 이름으로 저장 / 취소 를 묻습니다.

10. 쪽 편집 (썸네일, 편집 모드)

  • 순서: 썸네일을 끌어 놓기 또는 Alt+↑/↓. 삭제: Delete 또는 우클릭 '삭제'.
  • 회전: 우클릭 왼쪽/오른쪽 90° 회전. 숨김: '숨김 / 숨김 해제 / 숨김 전체 해제'(숨긴 쪽은 오른쪽에 '숨김' 띠).
  • 쪽 넣기: '복사'(Ctrl+C) → '붙여넣기'(Ctrl+V, 다른 PDF 에도) · '스크린샷 붙여넣기'(스크린샷 카드 전부를 새 쪽으로) · '클립보드 붙여넣기' · 그림 파일이나 스크린샷 카드를 썸네일로 끌어 놓기. '새 페이지 넣기' 는 누른 썸네일 쪽 크기의 흰 쪽을 그 아래에 넣습니다 — 바로 사진·선·글을 넣을 수 있고 💾 저장해야 들어갑니다.
  • 크롭·쪽 나누기(본문 툴바 '+' 오른쪽 크롭 단추): 여백은 한 변 95% 까지(마주 보는 두 변의 합 95% 까지). 쪽 나누기 — 좌우 2쪽·위아래 2쪽·4쪽: 크롭한 뒤 남은 영역을 나눔선(기본 가운데, 미리보기의 파란 선을 끌어 조정)으로 나눠 1쪽을 2쪽·4쪽으로 만듭니다. '오른쪽 조각부터' 는 오른쪽에서 펼치는 책용. 나눈 쪽은 썸네일·본문에 바로 보이고 💾 저장을 눌러야 원본에 들어갑니다(취소하면 되돌림).
  • 다른 파일로 끌어 복사: 썸네일(여럿 가능)이나 스크린샷 카드를 끌어 책갈피창의 다른 파일·책갈피 위에 잠시 머물면 그 파일이 열립니다. 썸네일 위로 옮겨 원하는 썸네일에서 놓으면 그 아래에 복사됩니다(💾 저장해야 들어감). 저장하지 않은 편집이 있으면 다른 파일을 열지 않습니다.
  • 쪽 편집은 💾 저장 또는 '변경 적용 — 새 PDF로 저장...' 으로 반영합니다.

11. 인쇄 · 다단 · 병합 · 이미지→PDF · 암호화

  • 파일 → 인쇄...(Ctrl+P): 범위(문서 전체 · 현재 페이지 · 선택한 썸네일 · 선택한 책갈피 파일 · 페이지 범위 · 스크린샷) · 미리보기 · 프린터 · 용지 · 인쇄 크기(맞춤/실제 크기/배율) · 색상(컬러/흑백) · 단면/양면 · 포함(문서 + 주석·꾸미기 / 문서만) · 부수. PDF로 인쇄 로 파일로도 저장합니다.
  • 다단 생성...(도구 → 다단 생성...): 본문에 연 PDF 하나를 다단(1단 포함)으로 새 파일에 만듭니다. 설정은 다단 인쇄와 같고(스타일 공유), 간지·문서마다 새 쪽 같은 여러 파일 항목은 없습니다. 목차는 책갈피 1단계로, 책갈피는 원본 그대로 옮깁니다.
  • 다단 인쇄(인쇄 창 '다단 인쇄' → 설정): 한 장에 1·2·4·6·8쪽, 채움 방식, 인쇄 면(단면/양면), 제본 여백, 맞쪽 인쇄(맨 앞 여백 페이지 1장 추가), 문서마다 새 페이지·홀수 쪽 시작, 쪽번호(위치·글꼴·배경 블록), 선, 표지·목차·간지(Word 양식, 샘플 저장 가능). 설정은 스타일로 저장합니다.
  • 변환(파일·도구 탭 '변환' · 책갈피창 우클릭 '변환...' · 썸네일 우클릭 '선택한 쪽 변환'): PDF 를 Word·한글 HWPX·PowerPoint·Excel(표)·텍스트·이미지로 바꿉니다. Word·HWPX 는 두 방식 모두 고칠 수 있는 글입니다 — 편집 가능은 끊긴 줄을 문단으로 잇고, 모양 그대로는 원본 줄·들여쓰기·간격·글자 크기·자간을 맞춰 원본처럼 보이게 합니다. Word 가 설치된 PC 에서는 Word (Microsoft Word 사용) 도 고를 수 있습니다(Word 가 직접 바꿈). 그림은 그림으로, 그림 제목은 글로 들어가고, 머리말·꼬리말은 각 형식의 머리말·꼬리말로, 쪽 번호는 자동 번호(한글은 '쪽 번호 매기기')로 들어갑니다. 같은 폴더에 같은 이름으로 저장하고, 이름이 겹치면 (2) 를 붙입니다. 문서 전체·쪽 범위·고른 쪽을 고를 수 있고, 책갈피창에서 여러 파일을 고르면 한꺼번에 바꿉니다.
  • PDF 병합(도구 → PDF 병합..., Ctrl+M · 책갈피창에서 여러 파일 우클릭): 오른쪽 목록 순서대로 하나로 합칩니다. 스크린샷 리스트도 넣을 수 있고, 미리보기 · 용량 줄이기 · 다단 생성 옵션. 끝나면 새 창으로 열지 묻습니다.
  • 이미지 → PDF 변환...: 그림 목록(위→아래 = 쪽 순서, 끌어서 순서 변경) · 미리보기 · 다단 저장 · PDF로 저장.
  • 암호화 (암호·권한 설정)...: 여는 암호, 권한 암호(인쇄 · 변경 · 복사 허용 범위), 256-bit AES(권장) / 128-bit AES. 암호가 걸린 파일은 책갈피창 우클릭 '암호 입력' 으로 엽니다.

11-1. 전자서명 (본문 툴바 크롭 오른쪽 단추 · 도구 → 전자서명 ▸)

  • 서명 그림...: 종이에 한 서명을 찍은 사진(또는 투명 PNG)을 불러오면 배경을 지워 투명하게 만들고, 잉크 색(원래 색·검정·파랑)을 고르고, 서명 둘레로 잘라 이름을 붙여 둡니다. 클립보드의 그림도 됩니다.
  • 디지털 ID...: 이름·이메일·유효기간·비밀번호로 디지털 ID 를 새로 만들거나 가지고 있는 .pfx/.p12 를 가져옵니다. 만든 뒤에는 백업 내보내기로 .pfx 를 안전한 곳에 두세요 — PC 가 고장 나면 같은 ID 로 다시 서명할 수 없습니다. 공개 인증서 내보내기(.cer)는 받는 사람에게 줍니다. [공동인증서 가져오기…] 는 PC·USB 의 NPKI 폴더에서 공동인증서를 찾아 인증서 비밀번호로 가져옵니다(원래 폴더는 그대로, 비밀번호도 같습니다). [Windows 인증서 저장소에서…] 는 Windows 에 들어 있는 인증서(스마트카드·USB 토큰 포함)를 키를 복사하지 않고 씁니다 — 서명할 때 Windows 가 PIN 을 물을 수 있습니다.
  • 서명하기 — 자리를 놓고, 한 번에 확정: 크롭 오른쪽 전자서명 단추(또는 도구 → 서명...)를 누르고 본문에서 서명 그림이 들어갈 자리를 끌어 정합니다(클릭만 하면 기본 크기). 본문 우클릭 → 여기에 서명… 은 누른 자리에 기본 크기로 놓습니다. 끌면 바로 서명하지 않고 서명 자리(점선 상자)가 생깁니다 — 끌어 옮기고, 오른쪽 아래 모서리로 크기를 바꾸고(그림 비율 유지, Shift 를 누르면 자유), Delete 로 지웁니다. 한 쪽에 여러 개를 놓아도 됩니다. 우클릭하면 '그림만(전자서명 아님)'·'다른 쪽에도 놓기…' 가 있습니다. 편집 모드의 그리기 도구가 켜져 있어도 서명 단추를 누르면 도구가 꺼집니다. 다 놓았으면 본문 위 띠의 [서명 확정…] — 디지털 ID·서명 그림·겉모양 글자(이름·날짜·사유)를 고르고 [Windows Hello 로 서명] 또는 비밀번호를 넣어 [서명 확정]. 모든 자리가 한 번에 서명되어 새 파일 '이름_서명.pdf' 로 저장되고 원본은 그대로입니다. 2쪽 보기에서는 자리를 놓을 수 없습니다. 회전한 쪽에도 글 방향대로 서명됩니다.
  • 서명 고치기: 서명한 파일을 열면 본문 위 띠에 [서명 편집] 이 있습니다(내 디지털 ID 로 한 서명). 누르면 서명이 다시 자리로 돌아가므로 옮기거나 크기를 바꾸거나 지운 뒤 [서명 확정…] 하면 그 서명 파일이 바뀝니다. 다른 사람의 서명이 뒤에 있으면 고칠 수 없습니다.
  • 그림만 넣기: 도구 → 그림만 넣기... 는 전자서명 없이 등록된 서명 그림만 넣습니다(서명 효력이 없는 그림입니다). 자리 놓기·확정은 서명과 같습니다.
  • 서명 창의 더 많은 선택: 서명 종류 — 승인 서명(기본) 또는 인증(변경 금지 / 양식 채우기·서명 허용 / 주석·양식·서명 허용, 문서의 첫 서명일 때만) · 글자 배치 — 그림 위·글자 아래(기본 — 그림은 끈 상자에 꽉 차게, 글자는 상자 아래에 붙고 길면 줄을 바꿔 다 보입니다) / 그림 위에 겹쳐 / 그림 왼쪽·글자 오른쪽 · 타임스탬프 — 기관(TSA) 주소를 넣고 켜면 기관의 시각이 들어갑니다(인터넷 필요, 기본은 꺼짐). 서명 그림 창에서는 손으로 그리기… 도 됩니다.
  • 빈 서명 칸: 도구 → 빈 서명 칸 만들기... 로 본문에 서명할 자리를 끌고 이름(예: 승인자)을 붙여 두면, 받은 사람이 그 칸에 서명합니다. 빈 칸이 있는 문서는 본문 위 띠에 '빈 서명 칸' 이 보이고, 서명 단추를 누르면 [빈 칸에 서명] 을 고를 수 있습니다(칸 안을 끌거나 우클릭해도 그 칸에 서명). 작성자가 인증한 문서는 빈 칸에만 서명할 수 있습니다. 칸을 만들 때 서명할 사람을 그 사람의 공개 인증서(.cer)로 정할 수 있고, 이 칸에 서명하면 문서의 모든 칸을 잠금을 켜면 그 서명 뒤에는 어떤 칸도 바꾸거나 서명할 수 없습니다(마지막 서명 칸에 쓰세요).
  • 비밀번호: Windows Hello(지문·PIN)를 쓸 수 있는 PC 는 디지털 ID 를 만들 때 비밀번호를 Hello 로 잠가 보관하고, 서명할 때 Hello 확인만 합니다. Hello 를 못 쓰면 비밀번호를 Google 비밀번호 관리자 등에 저장해 두고 붙여넣으세요(Ctrl+V). PolyPDF 는 비밀번호를 그대로 저장하지 않습니다.
  • 서명 확인: 서명된 문서를 열면 본문 위 띠에 ✅ 유효·신뢰함 / ⚠ 유효·신원 미확인 / ⚠ 서명 뒤 변경됨 / ❌ 무효 가 보이고, [서명 패널]에서 서명자·시각·인증서 지문을 보고 [이 인증서 신뢰]로 등록합니다(지문을 그 사람에게 확인한 뒤에만). [서명 시점 판 저장…] 은 그 서명을 할 때의 파일 그대로를 새 PDF 로 저장합니다.
  • 서명한 뒤 저장: PolyPDF 로 그 파일을 다시 저장(책갈피·쪽 편집·크롭 등)하면 서명이 깨집니다 — 그때는 새 파일로 저장할지 묻습니다. 서명 전에 저장하지 않은 편집이나 PDF 에 아직 들어가지 않은 꾸밈이 있으면 [저장하고 서명] 을 묻습니다 — 저장한 판에 서명해야 서명에 들어갑니다.
  • 알아 둘 것: 직접 만든 디지털 ID 는 받는 사람의 PDF 뷰어에서 '신원 알 수 없음' 으로 보입니다 — 받는 사람이 공개 인증서(.cer)를 신뢰 등록하면 '유효' 로 보입니다. 문서가 서명 뒤 바뀌었는지는 신뢰 등록 없이도 드러납니다. 서명 시각은 서명한 PC 의 시계 기준입니다. 제출처가 공동인증서 등 정해진 인증서를 요구하면 직접 만든 ID 로는 대신할 수 없습니다 — 그 인증서를 가져와 서명하세요.

12. 텍스트 창 · OCR

  • 📄 텍스트 탭(보기 → 텍스트): 현재 쪽의 본문 글자를 보여 줍니다(이어 보기에서는 화면 가운데 쪽). 스타일(제목·내용의 글꼴·크기·굵게·자간·줄간격), 표 생략, 문장 잇기.
  • 줄 단위로 글자를 고칠 수 있고, 줄을 고르면 본문에서 그 자리가 표시됩니다. 하이라이트 · 본문에도 표시 · 책갈피로(하이라이트한 곳을 책갈피로) · Word 저장 ▾(현재 쪽 / 쪽 범위 / 문서 전체).
  • OCR 로 읽기(툴바 OCR · 도구 메뉴 · 텍스트 창): 스캔 PDF 의 글자를 읽습니다 — 현재 쪽 / 쪽 범위 / 문서 전체, 언어, '뒷배경 워터마크는 읽지 않기', '글자가 이미 있는 쪽은 건너뛰기'. PDF 에 반영 으로 글자층을 PDF 에 넣습니다(원본은 백업). OCR 엔진은 도구 → 구성요소 설치(녹화·OCR)… 에서 받습니다.
  • OCR로 글자층 생성(책갈피창에서 파일 여러 개나 폴더 행을 골라 우클릭): 고른 PDF 들의 글자층 없는 스캔 쪽을 한 번에 OCR 로 읽어 보이지 않는 글자층을 원본에 넣습니다 — 다른 프로그램에서도 검색·복사가 됩니다. 처음 한 번 원본 옆에 백업을 남기고, 이미 읽은 쪽은 다시 읽지 않으며, 서명된 PDF·암호 PDF 는 건너뜁니다.
  • 용량 줄여 내보내기(책갈피창 우클릭 — 파일 여러 개·폴더 행도): 그림 해상도·품질만 낮춰(약 200 · 보통 150 · 강 100 dpi) 용량을 줄인 새 파일 <이름>_압축.pdf 를 만듭니다. 글자와 원본은 그대로, 5% 넘게 줄지 않으면 만들지 않습니다.
  • 개인정보 지우고 별도 저장(책갈피창 우클릭): 가림 창에서 쪽 그림을 끌어 영역을 고르거나, 주민등록번호·전화번호·이메일·카드번호· 사업자등록번호·검색어를 찾아 목록에 넣습니다(스캔 쪽은 OCR 결과로 찾음). 그 자리의 글·그림을 실제로 지운 새 파일 <이름>_가림.pdf 를 만들고, 문서 정보·첨부 파일 같은 숨은 데이터도 지웁니다. 원본은 그대로입니다.
  • 두 파일 비교(책갈피창에서 파일 두 개를 골라 우클릭): 2단 보기로 왼쪽에 옛판(수정 시각이 이른 파일), 오른쪽에 새판을 띄우고 지운 줄은 빨강, 넣은 줄은 초록, 바뀐 줄은 노랑으로 칠합니다. 변경 목록 창에서 항목을 누르면 두 창이 함께 그 쪽으로 가고, 창을 닫으면 칠한 것이 지워집니다.

13. 발표 보기 · 녹화 (F5)

  • 발표보기(F5 · 툴바 · 보기 메뉴 · 본문 우클릭): 전체화면. 화면 위쪽에 마우스를 대면 상단 띠 (쪽 이동 · 선 1~N · 선 종류 · 일부분 지우기 · 청소 · 본화면 적용 · 링크실행 · ⏱ 발표시간 · ● 녹화 · ✕ 종료 · 🖥 본화면/다른 화면)가 나오고, 왼쪽 가장자리에 대면 썸네일이 나옵니다. 본문에 그린 선·도형·글·사진도 그대로 보입니다.
  • 마우스: 왼쪽 끌기 = 선긋기, 왼쪽 10% 클릭 = 이전 쪽, 그 밖 클릭 = 다음 쪽. 키: → Space PgDn ↓ 다음 · ← PgUp ↑ 이전 · Home/End · 숫자+Enter 쪽 이동 · S 상하 2분할 · D 좌우 2쪽 · Esc 종료. 끝 쪽에서는 다음 파일로 넘어갑니다.
  • 우클릭: 포인터·포인터 설정, 선(펜)·선 설정, 선 지우기, 상하 2분할(중앙겹침 %), 좌우 2쪽(맞쪽), 화면 채움, 보기 설정(자르기), 발표시간 설정(준비내용·시간·알람), 타이머 시작시 녹화시작, 화면(모니터) 선택.
  • 상단 띠 맨 오른쪽 🖥 화면2로 / 🖥 본화면으로(누르면 갈 곳): 발표 창을 다른 모니터로 옮기거나 뷰어가 있는 모니터로 되돌립니다. 고른 것은 기억해 다음 발표도 그 화면에서 엽니다(모니터가 하나면 꺼져 있음).
  • '본화면 적용' 을 켜 두면 끝낼 때 그린 선을 본화면 · PDF · 둘 다 중 어디에 남길지 묻습니다.
  • 녹화(Ctrl+R 녹화/재개, Ctrl+Shift+R 중지): 화면+음성을 mp4 로. 환경설정 화면+음성 녹화 에서 저장 위치 · 오디오(영상만/마이크/시스템 소리/마이크 + 시스템) · 장치 · 단축키를 정하고 녹화 테스트 (3초) 로 확인합니다. ffmpeg 는 구성요소 설치 에서 받습니다.

14. 즐겨찾기 · 파일 태그

  • 즐겨찾기 탭: 현재 폴더 추가 · 현재 파일 추가 · 현재 검색어 추가 로 등록하고, 등록 폴더 · 등록 파일 · 등록 검색어 · 기타 목록에서 엽니다. 등록 폴더·파일의 앞 5개는 단추로도 보입니다. 항목 관리 에서 종류별로 순서·이름·단추 이름·삭제. 책갈피창 우클릭으로도 추가합니다.
  • 해시태그: 파일 우클릭 해시태그 편집... 으로 태그를 붙이고, 책갈피창 # 단추에서 형식·주제별 태그를 골라 #태그 로 검색합니다.
  • 자동 부여(환경설정 '파일 해시태그·키워드 자동 부여', 기본 꺼짐): 인덱싱 뒤 내용으로 태그를 붙입니다(·# 로 표시). 도구 → 🏷️ 구역에서 태그 다시 계산 · 새 태그 후보 검토 · 직전 자동 부여 되돌리기 · 자동 태그 전체 삭제 · 없는 파일 항목 정리.

16. 설정 (도구 → 환경설정...)

  • 언어 / Language (창 맨 위): 한국어 / English — 다시 시작하면 적용. 외부 언어팩 사용.
  • 화면 스타일: 자동(시스템) / 밝게 / 어둡게.
  • 시작 시 동작: 마지막에 열었던 폴더·파일 / 지정한 폴더·파일 / 빈 화면 · 마지막으로 본 페이지 열기 · 해시태그 자동 부여 · PolyPDF 시작 모드(편집 / 보기).
  • 스크린샷 한도 (5~1000, 일괄 캡쳐 시 자동 확장)
  • 리본 메뉴: 리본 메뉴 보이기 · 모음 메뉴 관리 · 마지막/첫 페이지에서 다음·이전 파일로 이동 · 페이지 이동 방식 · 쪽 넘김 애니메이션 · 가벼운 넘김(자동/항상/끄기).
  • 하이퍼링크: 쪽 위 단추의 위쪽 여백.
  • 고급 설정...: 인터넷 사전 (단어장) · 번역 (Claude) 의 API 키(§5) — 별도 창, 확인하면 바로 저장. 그 아래 발표화면 녹화 설정...: 저장 위치·오디오·장치·단축키·녹화 테스트(§13) — 별도 창.
  • 도구 메뉴: 단축키 설정... · 사전 및 용어집 관리 ▸. 환경설정 창 맨 아래: 현재 설정을 기본값으로 저장(배포용)… · 설정 초기화(기본값으로 되돌리기)….

17. 도움말 · 업데이트 · 구성요소

  • 본 사용법은 메뉴 → 도움말 → 사용법 으로 언제든 확인.
  • 버전·저작권·라이선스(GNU AGPL v3)·오픈소스 고지는 메뉴 → 도움말 → 정보.
  • 업데이트 확인: 새 버전이 있으면 버전별로 무엇이 바뀌는지 보여 줍니다. [업데이트] 를 누르면 파일을 먼저 받은 뒤, 열린 PolyPDF 창을 모두 닫고 설치합니다(받기를 취소하거나 실패하면 닫지 않습니다). 업데이트 자동 다운로드(기본 켜짐)는 새 버전을 미리 받아 둡니다. 베타(테스트) 버전도 받기는 1.0 전에는 늘 켜져 있습니다.
  • 도구 → 구성요소 설치(녹화·OCR)…: 녹화용 ffmpeg 와 OCR 엔진을 받습니다(설치됨 ✓ / 미설치).
  • 도구 → 가상 프린터(PolyPDF) 설치·제거…: 다른 프로그램(PowerPoint·Word·메모장 등)에서 'PolyPDF' 프린터로 인쇄하면 저장 창 없이 PDF 로 저장하고 PolyPDF 에서 엽니다. 저장 폴더는 원래 파일이 있는 폴더(찾지 못하면 기본 저장 폴더), 같은 이름이 있으면 (1)(2) 를 붙입니다. 창에서 저장 폴더·흑백을 고릅니다. 설치판에서만 쓸 수 있습니다(휴대용 판 제외). 프로그램 설치 때 함께 설치할 수도 있습니다. 인쇄 경로라 하이퍼링크·책갈피는 남지 않습니다 — 필요하면 원래 프로그램의 'PDF로 저장' 을 쓰세요. 인쇄한 뒤 Windows 기본 프린터가 바뀌는 것은 Windows 설정('Windows 에서 기본 프린터 관리')이 하는 일입니다.
