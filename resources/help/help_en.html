Using PolyPDF

1. Getting started

  • File → Open Folder (Ctrl+O) — choose a folder that contains PDFs. If the folder has a bookmarks.json, it is shown as a bookmark tree; otherwise all PDFs are listed in a flat tree.
  • File → Open File (Ctrl+Shift+O) — open a single PDF. Favorites → Recent Folders / Recent Files reopen what you opened before.
  • You can also drag and drop a PDF file or folder onto the window.
  • If you open several PDFs at once from File Explorer they gather in one window; files opened later open in a new window.
  • The first time you open a folder, its text is indexed in the background (progress in the status bar). If search results look out of date, use Tools → Index (rebuild).
  • Edit mode / view mode: switch with the Edit button above the bookmark panel (blue pencil = view, red pencil = edit). The mode at startup is PolyPDF startup mode under 'General › Startup' in Settings.
  • Tools → Install & Setup → Set as Default PDF App: opens the Windows Default apps page — choose PolyPDF for .pdf there (Windows does not let an app change the default by itself).

2. Screen layout

  • Bookmarks panel (left): click to load the file in the main viewer. Expand a file node (▸) to see the PDF's own bookmarks (TOC). Along the top: the Search list names box · # (hashtags, §13) · Sort (§7) · 📁 Folder (file mode ↔ folder mode) · Tree (single ↔ tree) · ↻ (refresh after files change outside — also in edit mode; asks first if there are unsaved changes).
  • Right-click a file or bookmark: Print / Rotate file ▸ / Open in File Explorer · New Folder · Rename File/Bookmark · Delete File/Bookmark / Save ▸ (Save · Save As · Flattened copy · Reduced-size copy · Redacted copy · Transfer bundle · Save as PDF · Convert) / Split View · Presentation · Expand/Collapse All Bookmarks / Read with OCR · Create text layer with OCR · Batch OCR · Build Bookmarks · Compare two files (with two chosen) · Sign · Edit Hashtags / add to Favorites, and so on. When a menu line shows a key, that key does the same thing to that row while the bookmark panel has focus (e.g. Ctrl+P Print · F5 Presentation · Ctrl+Alt+O Read with OCR act on the row's file or bookmark pages). In edit mode there are also Copy to folder / Move to folder (below New Folder), rename / delete folder, and merging several files into a PDF.
  • Expand All Bookmarks (right-click): expands the bookmarks of every file visible in the panel. While it is on (checked in the menu), files that appear as you scroll or as the list changes are expanded too. Collapse All Bookmarks turns this off and collapses back to the file rows.
  • Page thumbnails (second column): every page of the current PDF. Click to jump. Filter with the buttons on top: All · Shown (pages not hidden) · Marked (pages with lines, shapes, text or photos) · Hidden. Right-click a thumbnail → print · copy to screenshots · page editing (§9) · (edit mode) 'Add Bookmark' (to the current file in the tree) · 'Add Hyperlink'.
  • Main viewer (center): toolbar = 📷 All ▾ (screen capture) · ▶ All ▾ (read aloud) · mp3. Click the icon or label of the capture and read buttons to run them; the ▾ part on the right (or Alt+↓ · F4) opens the menu — the label shows the current capture mode / reading range. In edit mode the annotation tools (§8) follow. Page navigation (‹ [page] /N ›) is at the bottom centre of the window. The fit combo (fit page / two pages / fit width / manual) is at the bottom right, left of + 0 − — it applies to the main view (the active pane in split view). The vertical scrollbar on the right shows your progress through the whole document (drag to move). The info line at the left end of the bottom bar: file name · number of pages · current page paper (A4 portrait etc.) · file size, plus password · signed · scanned when they apply. Click it for the Document Info window (title · author · creator · created/modified dates · PDF version · permissions · signatures · pages with/without a text layer · bookmark count · attachment count) — Alt+Enter does the same (it is not in the right-click menus). In split view each pane has its own line. Right-click the page (or Shift+F10) — the six menus (bookmark panel · thumbnails · page, PDF and photo) share one order: Print → Copy (Copy · Copy as Screenshot · Copy Text · Paste …) → Shape (Rotate · Crop · Hide · Delete) → File ▸ → Save ▸ (click the label to save at once; ▸ holds Save As · Flattened copy · Reduced-size copy · Redacted copy · Transfer bundle · Save as PDF · Convert) → View (Split View · Presentation) → Tools (Read with OCR · Sign · Add Bookmark · Add Hyperlink) → Input Settings. On a row with ▸, clicking the label or pressing Enter does the main action; hovering ▸ or pressing → opens the submenu. In edit mode, pressing Del with no object selected deletes this page (until you save). Menus show each item's shortcut on the right. Paste uses what you copied last — copied pages go below this page, copied objects go where you clicked. Paste from Clipboard pastes pages and pictures as a picture and text as a text box.
  • Menu tabs: click Quick Access · File · Favorites · View · Tools · Help at the top of the window and the tab's commands appear in one row below it (Alt+C·F·V·B·T·H also switch tabs). Quick Access holds the buttons you use most and is shown at start; add, remove or reorder them with Manage Quick Access (Settings › Advanced › Ribbon) or by right-clicking the tab bar (Alt+C opens the tab). Turn off Show Ribbon there and the ribbon only appears briefly when you click a tab. The search box is at the right end of the tab row.
  • View buttons (Quick Access · View tab): Single (hide the right panel) · Split · Text · Search · Screenshots · Presentation (§12).
  • Split View (Ctrl+Shift+2): splits the main viewer into two panes so you can view two PDFs at once. Click a pane to make it active (blue border); bookmarks, search, thumbnails and reading then work on the active pane, and each pane's 📷 capture, read and mp3 buttons work on that pane alone. Right-click 'Open in Other Pane' opens the same document and page in the other pane. Saving in one pane leaves the other pane on its file and page.
  • Sliding panel: in split view, or when search and screenshots are both hidden, the right panel becomes a slide-out drawer that you open with the edge handle (‹) (it opens briefly during a capture and closes after 1.5 seconds). With only screenshots on, it shows as a grid.
  • Right panel: top = 📄 Text · 🔎 Search tabs, bottom = screenshots. When all screenshots are deleted, the screenshot area hides itself.

2-1. Read aloud (TTS) · mp3

  • Toolbar ▶ = read the body text from the current page / stop (headers, tables, formulas and figures are skipped). The sentence being read is highlighted in light blue, and pages follow automatically. Click a sentence to read from there.
  • The read button's ▾: range Once / Continuous / All / Full, continuous, plus speed (Slow · Normal · Fast · Very fast) and voice (auto picks one per language).
  • Toolbar mp3 (MP3 icon): saves the current PDF as mp3 files (+ .lrc lyrics), split by bookmark level (1/2/3) (one file if there are no bookmarks).

2-2. Turning pages (wheel · trackpad · keyboard)

  • Wheel: a zoomed page scrolls inside the page first; at the edge, scroll a little more to go to the next page. With fit page, one notch = one page. Trackpad momentum never turns the page. Ctrl+wheel = zoom.
  • Page navigation (Settings): Single page (default; 'Page-turn animation' on or off) / Continuous (adjacent pages joined, smooth scrolling — the page in the middle of the screen is the current page). 2-page view and the screenshot view always go one page at a time.
  • Light page turning (Settings, automatic by default): turns on by itself when the Windows power mode is 'Best power efficiency' or battery saver, or when page turning is slow, and the status bar shows 🔋 Light page turning. The page-turn animation is off, pages in between are skipped when you turn several in a row, the Text pane follows once you stop, and the next pages are drawn in advance. Heavy jobs such as OCR or conversion then tell you that they may take longer.
  • Go to next/previous file from last/first page (Settings, on by default): scrolling past the end shows the first (last) page of the next (previous) PDF and asks whether to open it. Choosing a file in the bookmark panel never asks.
  • Keyboard: PgUp/PgDn one page · ↑/↓/Space (Shift+Space back) move inside the page first, then to the next page · Home/End first/last page · Ctrl+C copy text.

3. Search

  • Type in the search bar at the top right and press Enter. Matches are highlighted in the text. Next to the search box, Aa = match case and .* = regular expression (e.g. \d{4}-\d{2}) — the result list, highlights and F3 all follow the same rule.
  • Search ignores spaces and line breaks — it finds words split at the end of a line or typed with different spacing. For scanned PDFs, it searches the OCR text once you save it (that file is indexed again after saving).
  • Sort results: Bookmarks / Name / Matches.
  • F3 / Shift+F3 or the search bar's ▶ / ◀: next / previous match. After the last match in a file, it jumps to the first match of the next file in the results.
  • Filter by #tag: choose tags from the # button in the bookmark panel and #tag is added to the search (§13).
  • Save: save the results to Excel (.xlsx) (the file name gets a date-time prefix).
  • Capture all: take screenshots of every matching page in the results. If there are more results than the limit, the limit is raised automatically.
  • Keep searches you use often with Favorites → Add Current Search.

4. Screenshots / screen capture

  • Capture with the main toolbar's 📷 capture button or Ctrl+Shift+S. Choose the mode from the drop-down next to the capture icon: Full screen (current page / selected thumbnails) · Region capture (press and drag a box on the screen, move or resize it by dragging or with the arrow keys, then press Enter or double-click to capture · right-click to pick again · Enter at the start reuses the last region) · Custom size 1–5 (a box of a set size at the point you click; set names and pixel sizes in 'Custom Size Settings'). Capture quality (as shown / original quality). In Keyboard Shortcuts you can make screen capture a global shortcut (works over other programs).
  • Select several thumbnails and capture to save each page full screen in one go (the thumbnail right-click 'Copy to Screenshots' does the same).
  • Each screenshot card shows its order number underneath (updated when you reorder or delete). Drag cards to reorder; right-click 'Delete' (or 'Delete n selected') · 🗑 Delete All. In edit mode, drop a card onto the thumbnails to insert it as a new page.
  • Copy to Clipboard (📋, Ctrl+Alt+C): copies the screenshots to the clipboard in order → paste them one by one from the Win+V list.
  • Import from Clipboard (📥): adds the picture on the clipboard (copied from a capture tool, or image files copied in File Explorer) as screenshot cards.
  • In 2-page view, the left and right pages are saved as separate cards.
  • Click a screenshot card to show it in the main viewer. If there was a search term when it was captured, the original page is re-rendered with the highlight.
  • While showing screenshots, ◀ ▶ · page number · the right scrollbar · the mouse wheel move through the whole screenshot list, and the view combo switches page / width / custom zoom (fit page by default).
  • 💾 Save PDF or Ctrl+Alt+S: saves all screenshots into one PDF. In the options dialog choose ① highlight search terms (on = high-resolution re-render, off = original 1:1) ② file name at the top ③ page number at the bottom. Your choices become the defaults next time. After saving you are asked whether to load it in this window.
  • The screenshot list always starts empty; on exit, if it has cards, you are asked whether to save them as a PDF.

5. Build bookmarks automatically (Tools → Generate Bookmarks Automatically / right-click a file → 'Build Bookmarks')

  • Analyzes the current PDF (or the file you right-clicked in the tree) and builds bookmarks.
  • Modes: Auto (TOC if present, otherwise font; OCR automatically for scanned images) · Force TOC · Force font · Scanned/Image (OCR). OCR mode recognizes headings such as 'CHAPTER 1' in scanned books, with an option to include large text as headings.
  • If several bookmarks land on the same page, only chapter titles (CHAPTER 1) and numbers (1, 1.1) are kept and the noise is removed.
  • Scanned books too: it finds the table of contents pages (first 15 pages) and follows them. Pages already OCR'd (Text panel 'Read Again with OCR') are not read again, and newly read pages show in the Text panel right away.
  • Result: nothing is written to the PDF yet — the bookmarks go into that file in the Bookmarks panel unsaved (edit mode); check them and press [Save] to write them to the PDF. A bookmark .txt for ALPDF is created right away if you choose it.
  • Review table: Del = delete selected rows, [Edit Title] = edit the current row's title, [OK] = put them in the Bookmarks panel.
  • If it takes long, click the progress bar in the status bar and press [Stop] in the Tasks window. Pages already read are kept, so building again continues; the stop window lets you open the review table with what was found so far or discard the OCR results too.
  • OCR results are kept only when saved — use the status bar '💾 Unsaved OCR' button, the Bookmarks panel [Save], or the prompt on exit.

6. Editing bookmarks (the [Edit] button above the bookmark panel)

  • Turning Edit (pencil icon) on shows Cancel (undo every change since the last save) · Save and two rows of edit buttons. While editing, clicking a bookmark moves the main viewer there, and double-clicking opens the edit window. Right-click an item → Rename File/Bookmark / Delete File/Bookmark / Edit bookmark / Sort Selected Bookmarks by Page. Changing bookmarks (rename, delete, add, build automatically) works only in edit mode — in view mode you are asked whether to turn edit mode on (renaming or deleting files works any time). In split view, new bookmarks go into that bookmark panel; if both panels show the same file, both change.
  • ◀ / ▶: outdent / indent. ▲ / ▼: move up / down. You can also drag with the mouse.
  • 🗑️ Delete (bookmark = remove from tree · file = Recycle Bin), Shift + 🗑️ Delete (keep only the selected bookmarks and delete the file's others, after confirming), 📋 Copy (copy the selected files to another folder), 💾 Save (into the original PDF — for a new file use 'Save As' (F12), default name <original>_edited.pdf). You can also add a bookmark at the current page by right-clicking the viewer.
  • If you turn editing off with unsaved changes, you are asked Save / Revert (Don't Save) / Keep Editing.

7. Sorting the bookmark tree

  • The sort combo under the search bar: Bookmarks (default) · Name · Modified · Size.
  • If there is a bookmarks.json, its order is used; the combo re-sorts immediately only in the flat (folder–PDF) mode.

8. Annotations — lines · shapes · text · photos · hyperlinks (edit mode)

  • In edit mode the annotation tools are added to the page toolbar. Pens 1–5 (Ctrl+1–5; colour · width · opacity) · Lines (double-click: Straight line / Highlight / Freehand, Ctrl+`) · Shape (Rectangle / Rounded Rectangle / Circle; ▾ No fill · Semi-transparent fill · Fill) · Text (text box ↔ Callout text; ▾ styles: Body · Title · Note · Emphasis) · Select objects (move · resize · delete; drag a box to select several) · Eraser (thin Ctrl+E / thick Ctrl+Shift+E) · Clear (all lines on this page, Ctrl+Shift+Backspace) · ↶ Undo (Ctrl+Z) / ↷ Redo (Ctrl+Y) — undoes what you did in edit mode (decorations, photos, bookmarks, moving/deleting/splitting pages, hiding, rotation, hyperlinks, crop) in order, from anywhere in the window and across pages.
  • While typing, ▲▼ change the font size and ◀▶ the letter spacing. Move a selected object with the arrow keys (Shift = 1px); Del deletes it. While dragging, hold Ctrl to move a copy, Shift to move only horizontally or vertically, and Ctrl+Shift to move a copy only horizontally or vertically (as in PowerPoint).
  • Right-click on a selected object: with a text box, line or photo selected, the right-click menu shows only its options (for a text box, 'Text input settings' opens the input settings window on its Text tab). The crop and digital signature buttons appear only in edit mode.
  • Copy and paste: Ctrl+C → Ctrl+V copies selected text boxes, lines, shapes and photos (several selected with a box, too) — slightly offset on the same page, at the same place on another page or file. Right-click 'Copy' / 'Paste' pastes where you clicked. Drag with Shift held to move a copy and leave the original.
  • Right-click the page → Shape input settings / Text input settings: set pens 1–5, highlight opacity and eraser size, and text styles (font · size · colour · letter spacing · box line · background · alignment · callout end), and save them.
  • Photos: right-click 'Paste Photo' · 'Paste from Clipboard' (▼ Rectangle / Rounded Rectangle / Circle) · 'Paste Screenshots' (the cards selected in the screenshot pane, or all), Ctrl+V, or drop an image file. Ctrl+↑/↓ change a selected photo's opacity.
  • Add Hyperlink (right-click the page or a thumbnail, Ctrl+K): give it a label and either a file (a document, image, video etc. in the bookmark folder) or an external link (URL) (https, allowed domains). It shows as a blue button on the page. Executables are blocked. Hyperlinks are kept in N-up printing and exports.
  • Save (💾) = bookmarks, page edits, rotation and crop go into the original PDF, and annotations (lines, shapes, text, photos), hyperlinks and tags are also put into the PDF so other PDF viewers show them (a 'PolyPDF' layer you can hide in another viewer's layer panel). Keep editing in PolyPDF and save again. Signed documents do not get the annotation copy · Save As (F12) · Flattened copy (Save ▸) = a new file (_flattened.pdf) with annotations, photos and hyperlinks flattened into the page and the content outside a crop really removed (text stays searchable; the original is untouched). Use it for programs that ignore annotations, for submissions, or to remove cropped-out content. Signed documents are signed again at the same places (your digital ID is confirmed — cancel and that signature is left out).
  • If another PolyPDF window has the file open when you save, you are asked Close and Save / Save with New Name / Cancel.

9. Page editing (thumbnails, edit mode)

  • Order: drag a thumbnail, or Alt+↑/↓. Delete: the Delete key or right-click 'Delete'.
  • Rotate: right-click rotate left/right 90°. Hide: 'Hide / Unhide / Unhide All' (a hidden page shows a 'Hidden' band on the right).
  • Adding pages: 'Copy' (Ctrl+C) → 'Paste' (Ctrl+V, also into another PDF) · 'Paste Screenshots' (all screenshot cards as new pages) · 'Paste from Clipboard' · drop image files or screenshot cards onto the thumbnails. 'Insert New Page' adds a white page the size of the clicked thumbnail's page below it — you can add photos, lines and text right away; press 💾 Save to keep it.
  • Crop and split pages (crop button to the right of '+' on the page toolbar): margins up to 95% per side (opposite sides together up to 95%). Split Pages — 2 pages left/right, 2 pages top/bottom or 4 pages: the area left after cropping is split at the split lines (centre by default; drag the blue lines in the preview to adjust), turning one page into 2 or 4. 'Right part first' is for books read right to left. Split pages show at once in the thumbnails and the main view and go into the original only when you press 💾 Save (Cancel reverts).
  • Drag to copy into another file: drag thumbnails (several allowed) or screenshot cards and rest over another file or bookmark in the bookmark panel — that file opens. Move over the thumbnails and drop on the thumbnail you want — the pages are copied below it (applied with 💾 Save). Another file is not opened while there are unsaved edits.
  • Page edits are applied with 💾 Save or right-click 'Save ▸ Save As'.

10. Print · N-up · merge · images → PDF · encrypt

  • File → Print... (Ctrl+P): range (whole document · current page · selected thumbnails · selected bookmark files · page range · screenshots) · preview · printer · paper · print size (fit / actual size / scale) · colour (colour / black and white) · single/double-sided · include (Document + annotations / Document only) · copies. Print to PDF saves to a file.
  • Create N-up PDF (Tools → Create N-up PDF): turns the PDF open in the viewer into a new N-up file (1-up included). Same settings and styles as N-up printing, without the multi-file items such as dividers or a new page per document. The table of contents lists the top-level bookmarks; bookmarks are carried over as they are.
  • N-up printing (the print dialog's 'N-up printing' → settings): 1·2·4·6·8 pages per sheet, fit mode, sides (single/double), gutter, facing pages (adds 1 blank page at the front), each document / odd page start, page numbers (position · font · background block), lines, cover · contents · divider pages (Word templates; samples can be saved). Save the settings as a style.
  • Convert (File and Tools tabs 'Convert' · right-click 'Save ▸ Convert' in the bookmark panel, thumbnails or page): turns the PDF into Word, Hangul HWPX, PowerPoint, Excel (tables), text or images. Both Word/HWPX modes give editable text — editable joins broken lines into paragraphs; keep appearance keeps the original lines, indents, spacing, font sizes and letter spacing so it looks like the original. On a PC with Word installed you can also choose Word (using Microsoft Word), which lets Word do the conversion. Pictures stay pictures; captions are text; running headers and footers go into the format's own header/footer (page numbers become automatic page numbers — Hangul's page numbering). Saved next to the PDF with the same name; if that name exists, (2) is added. Choose the whole document, a page range or the selected pages; select several files in the bookmark panel to convert them together.
  • Merge PDFs (Tools → Merge PDFs, Ctrl+M · right-click several files in the bookmark panel → 'Save as PDF (N merged)'): joins the files in the order of the right-hand list. You can add the screenshot list too; there is a preview and options to reduce file size and make an N-up copy. When done it asks whether to open the result in a new window.
  • Images to PDF (Tools tab): picture list (top to bottom = page order, drag to reorder) · preview · save as N-up · save as PDF.
  • Encrypt (password · permissions) (Tools tab): an open password, a permissions password (what printing, changes and copying are allowed), 256-bit AES (recommended) / 128-bit AES. Open an encrypted file with right-click 'Enter Password' in the bookmark panel.

10-1. Digital signature (button to the right of Crop on the page toolbar · Tools → Digital Signature ▸)

  • Manage Digital IDs (Tools → Digital Signature ▸): create a new digital ID (name · email · validity · password) or import an existing .pfx/.p12. Each digital ID holds one signature image — Add Signature Image at the bottom of the new-ID window, or Signature Image… in the manager later. Enter the image's actual width (mm) — the height follows the image's proportions, and clicking on a document places the signature at that size. The manager shows the selected ID's details (including the image). Edit Details… changes a self-made ID's name · email · organization · validity · password · image by issuing a new certificate and deleting the old ID (documents already signed stay valid; send the new public certificate again). Load a photo of your signature on paper (or a transparent PNG, a clipboard image, or draw by hand): the background is removed, you pick the ink color (Original · Black · Blue), and it is cropped to the signature. After creating one, use Export Backup to keep the .pfx somewhere safe — if the PC fails you cannot sign with the same ID again. Give the public certificate (.cer, Export Public Certificate) to the people who receive your documents. Import Korean Certificate (NPKI)… finds Korean certificates in NPKI folders on the PC or a USB drive and imports one with its certificate password (the original folder is unchanged; the password stays the same). From Windows Certificate Store… uses a certificate held by Windows (including smart cards and USB tokens) without copying the key — Windows may ask for a PIN when you sign.
  • Signing — place, then confirm once: press the digital signature button to the right of Crop (or Tools → Digital Signature ▸ Sign). First you confirm it is you once — if a digital ID is stored with Windows Hello, the Windows Hello prompt (fingerprint · face · PIN) appears right away; cancel it to enter a digital ID password instead. The IDs that password opens are the ones you can sign with; with several, the default ID (or the first) is used (if none opens, enter it again or create a digital ID). Then drag on the page where the signature image goes (a single click puts the signature image at its actual size with its top-left at that spot — switching the ID resizes it to that ID's size). Right-click → Sign here works the same. Dragging does not sign yet — it makes a signature place (dashed box; the page shows through): drag it to move, use the bottom-right corner to resize (keeps the image ratio; hold Shift for free), press Delete to remove. You can put several on one page. Its right-click menu switches the digital ID (one of the opened ones — 'Manage Digital IDs…' below it edits the current ID's signature image, width and details; the image is changed only there) and turns the signature image, name and date on or off, and offers 'Image only (not a digital signature)' and 'Place on Other Pages…' — your choices are kept for next time. Drawing tools of edit mode are turned off when you press the signature button. When done, press Confirm Signatures in the band above the page (or Tools → Digital Signature ▸ Confirm Signatures), check the digital ID, signature image and appearance text (name · date · reason) and press Confirm Signatures (no password again). If both the image and all text are off, nothing is signed ('nothing to show'). Image and text sit at the left of the signature box. All places are signed at once into a new file 'name_signed.pdf'; the original stays unchanged. You cannot place signatures in two-page view. Rotated pages are signed in the text direction.
  • Changing a signature: a signed file shows Edit Signatures in the band above the page (for signatures made with your digital ID). It turns the signatures back into places — move, resize or delete them, then Confirm Signatures replaces that signed file. It is not possible when someone else's signature comes after yours.
  • Image only: Tools → Digital Signature ▸ Insert Image Only puts only the digital ID's signature image, without a digital signature (the image has no signature effect; the same identity check applies). The image keeps its ratio at the top-left of the box you drag; the rest stays empty. Placing and confirming work as for signatures.
  • More choices in the signing window: Signature type — approval signature (default) or certification (no changes / form filling and signing allowed / comments, forms and signing allowed; only as the document's first signature) · Text layout — image above, text below (default — the image fills the dragged box, the text goes below it and wraps so it is never cut off) / over the image / image left, text right · Timestamp — enter a timestamp authority (TSA) address and turn it on to add the authority's time (internet needed, off by default).
  • Empty signature fields: Tools → Digital Signature ▸ Create Empty Signature Field lets you drag a place on the page and name it (e.g. Approver); the recipient then signs in that field. A document with empty fields shows 'empty signature field' in the band above the page, and the signature button offers Sign in an empty field (dragging inside a field or right-clicking in it also signs that field). A document certified by its author can be signed only in its empty fields. When creating a field you can designate the signer by that person's public certificate (.cer), and Lock all fields in the document when this field is signed prevents any further change or signature after that signature (use it on the last signature field).
  • Password: on a PC with Windows Hello (fingerprint · PIN) the password is locked with Windows Hello when you create the ID, and starting to sign only asks for Windows Hello; the opened key is used only until you confirm or cancel that signing. Without Windows Hello, keep the password in a password manager such as Google Password Manager and paste it (Ctrl+V). PolyPDF never stores the password in plain text.
  • Checking signatures: a signed document shows a band above the page — ✅ Valid · Trusted / ⚠ Valid · Identity unknown / ⚠ Changed after signing / ❌ Invalid. Signatures shows the signer, time and certificate fingerprint; Trust This Certificate adds it (only after confirming the fingerprint with that person). Save Signed Version… saves the file exactly as it was when that signature was made.
  • Saving after signing: saving the file again in PolyPDF (bookmarks, page edits, crop and so on) breaks the signature, so you are asked to save to a new file. If there are unsaved edits or annotations not yet in the PDF, you are asked [Save and Sign] — only the saved version is covered by the signature.
  • Good to know: a self-created digital ID shows as 'identity unknown' in the recipient's PDF viewer until they trust your public certificate (.cer). Changes after signing are detected even without trusting it. The signing time comes from the signing PC's clock. Where a specific certificate is required, a self-created ID cannot replace it — import that certificate and sign with it.

11. Text pane · OCR

  • 📄 Text tab (View → Text): shows the text of the current page (in Continuous mode, the page in the middle of the screen). Styles (font · size · bold · letter spacing · line spacing for titles and body), Skip tables, Join sentences.
  • You can fix the text line by line; selecting a line marks that spot on the page. Highlight · Show in body too · To bookmarks (turn highlighted spots into bookmarks) · Save Word ▾ (current page / page range / whole document).
  • Read with OCR (Tools tab 'OCR' · Ctrl+Alt+O · right-click · text pane): reads the text of scanned PDFs — current page / page range / whole document, language, 'Ignore background watermarks', 'Skip pages that already have text'. Apply to PDF writes the text layer into the PDF (the original is backed up). Get the OCR engine from Tools → Install & Setup → Install Components (recording · OCR).
  • Batch OCR (Tools → Batch OCR · right-click a file): reads every page of the current PDF with OCR and makes the bookmarks in one go. If the document has a table of contents, only its entries become bookmarks, plus one 'Contents' bookmark on its first page. The result goes into the PDF when you click [Save] in the bookmark panel.
  • Create text layer with OCR (select several files or a folder row in the bookmark panel and right-click): reads the scanned pages without a text layer in all selected PDFs with OCR at once and adds an invisible text layer to the originals — other programs can then search and copy the text. A backup is kept next to the original the first time, pages already read are not read again, and signed or password-protected PDFs are skipped.
  • Reduced-size copy (right-click Save ▸ — in the bookmark panel several files or a folder row too): lowers only image resolution and quality (light 200 · medium 150 · strong 100 dpi) and saves a smaller new file <name>_compressed.pdf. Text and the original stay as they are; no file is made unless it shrinks by more than 5%.
  • Redacted copy (right-click Save ▸): in the redaction window, drag on the page to choose areas, or find resident registration, phone, email, card and business numbers or a search term (scanned pages use the OCR results). A new file <name>_redacted.pdf is made with the text and images in those places actually removed, and hidden data such as document info and attachments is removed too. The original stays.
  • Compare two files (select two files in the bookmark panel and right-click): split view shows the older file (modified earlier) on the left and the newer on the right, with deleted lines in red, inserted lines in green and changed lines in yellow. Click an item in the change list to move both panes to it; closing the list clears the colors.

12. Presentation · recording (F5)

  • Presentation (F5 · Quick Access · View tab · page right-click): full screen. Move the mouse to the top of the screen for the top bar (page · pens 1–N · line type · partial erase · clear · Apply to Main View · Open Links · ⏱ presentation timer · ● record · ✕ exit · 🖥 Main/Other Screen), and to the left edge for thumbnails. Lines, shapes, text and photos added in the main view are shown too.
  • Mouse: left-drag = draw, click in the left 20% of the screen (change the width with right-click 'Back zone') = previous page, click elsewhere = next page. Keys: → Space PgDn ↓ next · ← PgUp ↑ previous · Home/End · digits + Enter go to a page · S top/bottom split · D two pages · Esc exits. At the last page it moves on to the next file.
  • Right-click: pointers and Pointer Settings, pens and Line Settings, Clear Lines, Top/Bottom Split View (centre overlap %), Back zone (%), Two-Page View (facing pages), Fill Screen, View Settings (cropping), Presentation Timer Settings (preparation text · duration · alarms), Start Recording with Timer, and the screen (monitor).
  • 🖥 To Screen 2 / 🖥 To Main Screen (where a click takes you) at the far right of the top bar moves the presentation to another monitor or back to the viewer's monitor. The choice is remembered for the next presentation (disabled with a single monitor).
  • With 'Apply to Main View' on, when you finish you are asked where to keep the lines you drew: the main view, a PDF, or both.
  • Recording (Ctrl+R record/resume, Ctrl+Shift+R stop): screen + audio to mp4. In Settings → Advanced › Presentation Recording choose the save location · audio (video only / microphone / system sound / microphone + system) · devices · shortcuts, and check with Test Recording (3 s). ffmpeg is installed from Install Components.

13. Favorites · file tags

  • Favorites tab: add with Add Current Folder · Add Current File · Add Current Search and open them from the Saved Folders · Saved Files · Saved Searches lists. The first 3 saved folders and files also appear as buttons (the first of each group shows a folder or file icon). Reorder, rename, set button names or delete them by kind in Manage Items. You can also add from the bookmark panel's right-click menu.
  • Hashtags: tag a file with right-click Edit Hashtags, then pick tags by type and topic from the # button in the bookmark panel to search with #tag.
  • Automatic tagging (Settings 'Auto-assign file hashtags/keywords', off by default): after indexing, tags are added from the content (shown as ·#). Tools → Tags ▸ has Recalculate Tags · Review New Tag Candidates · Undo Last Automatic Tagging · Delete All Automatic Tags · Clean Up Missing File Entries.

15. Settings (Tools → Settings · Ctrl+,)

Type in the Search settings box at the top to keep only the matching items and highlight the matching rows. The list on the left is split into General and Advanced; at the bottom, [OK] (save and close) · [Apply] (save, keep the window) · [Cancel] (discard changes since the last Apply).

  • General › General: Language (after restarting) · theme auto (system) / light / dark · startup (the last folder/file / a chosen folder/file / a blank screen · the last viewed page · PolyPDF startup mode) · view type (PDF only / mixed).
  • General › View & Paging: page navigation · page-turn animation · go to the next/previous file from the last/first page · Show Ribbon.
  • General › Photos (mixed view type): slideshow auto-advance · backup folder for originals of straightened photos.
  • General › Hashtags: auto-assign file hashtags/keywords · automatic photo hashtags · photo kinds.
  • General › Screenshots: screenshot list limit (5–1000; raised automatically for batch captures).
  • Advanced › Keyboard Shortcuts: change any shortcut · restore defaults · global screen-capture shortcut. Advanced › Ribbon: Manage Quick Access.
  • Advanced › Presentation Recording: save folder, audio, devices, shortcuts and test recording (§12).
  • Advanced › Fine-tuning: light page turning (automatic/always/off) · top offset of the hyperlink buttons. Advanced › Maintenance: external language packs · Save Current Settings as Defaults (for distribution) · Reset Settings (restore defaults).

16. Help · updates · components

  • Open this guide any time from Help → User Guide.
  • Version, copyright, license (GNU AGPL v3) and open-source notices are in Help → About.
  • Check for Updates: if a new version is available, it shows what changes in each version. Pressing [Update] downloads the file first, then closes all open PolyPDF windows and installs (if you cancel the download or it fails, nothing is closed). At the bottom of that window, Download Updates Automatically (on by default) fetches new versions in advance. Also Receive Beta (Test) Versions (off by default) also fetches test versions before a stable release.
  • Tools → Install & Setup → Install Components (recording · OCR): downloads ffmpeg for recording and the OCR engine (installed ✓ / not installed).
  • Tools → Install & Setup → Install/Remove Virtual Printer: when you print to the 'PolyPDF' printer from another program (PowerPoint, Word, Notepad …), it saves a PDF without a save dialog and opens it in PolyPDF. It saves next to the original file (or in the default save folder if the original can't be found) and adds (1), (2) if the name exists. Choose the save folder, black-and-white and the photo/image resolution (only larger images are reduced, to keep the PDF light) in that window. Available in the installed version only (not the portable one); it can also be installed during setup. Because it goes through printing, hyperlinks and bookmarks are not kept — use the program's own 'Save as PDF' if you need them. If your Windows default printer changes after printing, that is the Windows setting 'Let Windows manage my default printer'.

17. Photo mode (PolyPix)

Available when View type under 'General › General' in Settings is set to Mixed (with the default 'PDF only' there is no photo mode).

  • Switching modes: the TV button at the far left of the ribbon (click to switch to the other mode) · Alt+1 = PDF mode, Alt+2 = photo mode. Each mode remembers its own last folder and last viewed photo (PDF and page in PDF mode). If there are unsaved edits you are asked first.
  • Screen: bookmark panel = the picture files in the folder (a zip with photos is one row) · thumbnails = the chosen photos (choose one and you get the whole folder) · main view = one chosen photo. ◀ ▶ · wheel · PgUp/PgDn go to the previous/next photo in the thumbnail strip. The search box finds photos by their info (name · date taken · camera · tags · saved OCR text). The info line at the bottom shows name · date · size · camera; click it for Photo Info (Alt+Enter does the same).
  • Right-click menu (bookmark panel · thumbnail strip · main view — same order as for PDFs): Print → Copy Photo → shape (Rotate 90° left · Rotate 90° right · Rotate 180° · Original Orientation · Crop · Remove Crop · Restore original) → file (Open in File Explorer · Copy to Folder ▸ · Move to Folder ▸ · Rename (F2) · Delete (edit mode)) → Save ▸ (Save = save orientation · Flattened copy · Redacted copy · Save as PDF · Convert ▸ JPEG · PNG · WebP) → view (Split View · Presentation) → tools (Read with OCR · Photo Info · Show Location on Map · Batch · Edit Hashtags). Ctrl/Shift+click in the thumbnail strip to choose several photos; the menu then works on all of them.
  • Rotate (Ctrl+] / Ctrl+[): rotates the view only; the original is unchanged. For a JPEG, Save ▸ Save (save orientation) changes only the orientation tag of the original (the image is not recompressed).
  • Crop (Ctrl+Shift+X): view and export the cropped shape — the original is unchanged. ❮ ❯ in the crop window carry on with the next photos, and [OK] applies them all at once. Straighten shape (perspective · curved edges) (key A): drag 8 points (4 corners and 4 edge midpoints) to turn a document shot at an angle or curved paper into a rectangle ([Reset points]). On [OK] you are asked [Save] (replace the original with the straightened photo; the original goes to a backup folder inside the photo folder, or the one set in Settings 'General › Photos') · [Save As] · [Save to another folder]. Undo a replaced photo with right-click Restore original (the current file goes to the Recycle Bin).
  • Presentation · slideshow (F5): shows the photos of the thumbnail strip full screen. Set the auto-advance interval in Settings 'General › Photos'.
  • OCR: the text pane's [Read with OCR] · Tools tab OCR (Ctrl+Alt+O) read the current photo and show it in the text pane — you can then drag over the text on the photo to select and copy it. Choose several photos and right-click Read with OCR (N) to read them one after another in the background (status bar progress bar → Tasks window [Stop]). As with PDFs, the results are kept only when saved (status bar '💾 Unsaved OCR').
  • Format conversion: the File tab's 'Convert' makes Word · Hangul HWPX · text from the text read (OCR first). Right-click 'Save ▸ Convert ▸ JPEG · PNG · WebP' saves a new file in another picture format (the original is unchanged).
  • Photos → PDF: right-click 'Save ▸ Save as PDF' opens the Images to PDF window with the chosen photos (the thumbnail strip also offers all photos in the strip). Annotations, view rotation and crop go in as they are shown. Printing works the same way.
  • Show Location on Map: shows the photos that have a GPS position on a map (OpenStreetMap) in your default browser — nearby photos are grouped with their count and dates, and [Select in PolyPDF] selects those photos in the app. Before map images are fetched you are told that the rough location of the visible area is sent to the map server.
  • Batch: rename the chosen photos (new name_001 …) · reduce size · change format — size and format make new files; the originals are unchanged.
  • Hashtags: automatic photo hashtags in Settings 'General › Hashtags' (on by default) add date-taken, region, device and screenshot tags, and photo kinds adds receipt · business card · document. Filter with # in the bookmark panel (also by the start, like #2026 or #2026-11).
  • zip: click a zip with photos to view the photos inside (read-only — the zip itself is unchanged). Right-click Extract here · Extract to another folder; in the thumbnail strip you can extract just the chosen photos. In PDF mode, a zip with PDFs can be expanded too.
  • Portable devices (iPhone · Android): connect with USB, unlock and tap 'Trust This Computer', and a 📱 row appears at the top of the bookmark panel. Click a photo folder to fetch and view its photos one by one (the device is only read); scrolling past the end of the thumbnail strip fetches the next folder. Right-click Copy to PC saves them on the PC.
