Using PolyPDF

1. Getting started

  • File → Open Folder (Ctrl+O) — choose a folder that contains PDFs. If the folder has a bookmarks.json, it is shown as a bookmark tree; otherwise all PDFs are listed in a flat tree.
  • File → Open File (Ctrl+Shift+O) — open a single PDF. File → Recent Folders / Recent Files reopen what you opened before.
  • You can also drag and drop a PDF file or folder onto the window.
  • If you open several PDFs at once from File Explorer they gather in one window; files opened later open in a new window.
  • The first time you open a folder, its text is indexed in the background (progress in the status bar). If search results look out of date, use Tools → Rebuild Index.
  • Edit mode / view mode: switch with the Edit button above the bookmark panel (blue pencil = view, red pencil = edit). The mode at startup is PolyPDF startup mode under 'On startup' in Settings.
  • Tools → Register as Windows Default PDF App…: adds PolyPDF to the 'Open with' list (choosing it as the default is done in Windows Settings — the dialog shows how).

2. Screen layout

  • Bookmarks panel (left): click to load the file in the main viewer. Expand a file node (▸) to see the PDF's own bookmarks (TOC). Along the top: the Search list names box · # (hashtags, §13) · Sort (§7) · 📁 Folder (file mode ↔ folder mode) · Tree (single ↔ tree) · ↻ (refresh after files change outside).
  • Right-click a file or bookmark: Open File Location · Save As · Save (for PolyPDF) · Save (for other viewers) · Rename File/Bookmark · Delete File/Bookmark · Build Bookmarks · Edit Hashtags · add to Favorites, and so on. In edit mode there are also Copy Files / Move Files, new folder / rename / delete folder, and merging several files.
  • Expand All Bookmarks (right-click): expands the bookmarks of every file visible in the panel. While it is on (checked in the menu), files that appear as you scroll or as the list changes are expanded too. Collapse All Bookmarks turns this off and collapses back to the file rows.
  • Page thumbnails (second column): every page of the current PDF. Click to jump. Filter with the buttons on top: All · Shown (pages not hidden) · Marked (pages with lines, shapes, text or photos) · Hidden. Right-click a thumbnail → 'Add Bookmark' (to the current file in the tree) · print · copy to screenshots · page editing (§9).
  • Main viewer (center): toolbar = ‹ [page] /N › · zoom −/+ · screen capture · read aloud ▶ + Range ▾ · mp3 · view combo (page / 2 pages / width / custom zoom). In edit mode the annotation tools (§8) follow. The vertical scrollbar on the right shows your progress through the whole document (drag to move). Right-click the page (or Shift+F10, View → Option Menu): Copy Text · Copy Text After Selecting a Block · Print Current Page · rotate 90° · Split View · Presentation; in edit mode also Add Bookmark · Add Hyperlink · Hide Page · insert photos.
  • View buttons (top panel toolbar · View menu): Single (hide the right panel) · Split · Text · Search · Screenshots · Presentation (§12).
  • Split View (Ctrl+Shift+2): splits the main viewer into two panes so you can view two PDFs at once. Click a pane to make it active (blue border); bookmarks, search, thumbnails and reading then work on the active pane, and each pane's 📷 capture, read and mp3 buttons work on that pane alone. Right-click 'Copy to Window 1 / Copy to Window 2' opens the same document in the other pane.
  • Sliding panel: in split view, or when search and screenshots are both hidden, the right panel becomes a slide-out drawer that you open with the edge handle (‹) (it opens briefly during a capture and closes after 1.5 seconds). With only screenshots on, it shows as a grid.
  • Right panel: top = 📄 Text · 🔎 Search tabs, bottom = screenshots. When all screenshots are deleted, the screenshot area hides itself.

2-1. Read aloud (TTS) · mp3

  • Toolbar ▶ = read the body text from the current page / stop (headers, tables, formulas and figures are skipped). The sentence being read is highlighted in light blue, and pages follow automatically. Click a sentence to read from there.
  • Range ▾: Once / Continuous / All / Full, continuous, plus speed (Slow · Normal · Fast · Very fast) and voice (auto picks one per language).
  • Toolbar mp3 (MP3 icon): saves the current PDF as mp3 files (+ .lrc lyrics), split by bookmark level (1/2/3) (one file if there are no bookmarks).

2-2. Turning pages (wheel · trackpad · keyboard)

  • Wheel: a zoomed page scrolls inside the page first; at the edge, scroll a little more to go to the next page. With fit page, one notch = one page. Trackpad momentum never turns the page. Ctrl+wheel = zoom.
  • Page navigation (Settings): Single page (default; 'Page-turn animation' on or off) / Continuous (adjacent pages joined, smooth scrolling — the page in the middle of the screen is the current page). 2-page view and the screenshot view always go one page at a time.
  • Go to next/previous file from last/first page (Settings, on by default): scrolling past the end shows the first (last) page of the next (previous) PDF and asks whether to open it. Choosing a file in the bookmark panel never asks.
  • Keyboard: PgUp/PgDn one page · ↑/↓/Space (Shift+Space back) move inside the page first, then to the next page · Home/End first/last page · Ctrl+C copy text.

3. Search

  • Type in the search bar at the top right and press Enter. Matches are highlighted in the text.
  • Sort results: Bookmarks / Name / Matches.
  • F3 / Shift+F3 or the search bar's ▶ / ◀: next / previous match. After the last match in a file, it jumps to the first match of the next file in the results.
  • Filter by #tag: choose tags from the # button in the bookmark panel and #tag is added to the search (§13).
  • Save: save the results to Excel (.xlsx) (the file name gets a date-time prefix).
  • Capture all: take screenshots of every matching page in the results. If there are more results than the limit, the limit is raised automatically.
  • Keep searches you use often with Favorites → Add Current Search to Favorites....

4. Screenshots / screen capture

  • Capture with the main toolbar's 📷 capture button or Ctrl+Shift+S. Choose the mode from the drop-down next to the capture icon: Full screen (current page / selected thumbnails) · Region (drag a box on the screen, move or resize it, then press Enter or double-click to capture) · Custom size 1–5 (a box of a set size at the point you click; set names and pixel sizes in 'Custom Size Settings'). Capture quality (as shown / original quality). In Keyboard Shortcuts you can make screen capture a global shortcut (works over other programs).
  • Select several thumbnails and capture to save each page full screen in one go (the thumbnail right-click 'Copy Selected Pages to Screenshots' does the same).
  • Each screenshot card shows its order number underneath (updated when you reorder or delete). Drag cards to reorder; right-click 'Delete' (or 'Delete n selected') · 🗑 Delete All. In edit mode, drop a card onto the thumbnails to insert it as a new page.
  • Copy to Clipboard (📋, Ctrl+Shift+C): copies the screenshots to the clipboard in order → paste them one by one from the Win+V list.
  • Import from Clipboard (📥): adds the picture on the clipboard (copied from a capture tool, or image files copied in File Explorer) as screenshot cards.
  • In 2-page view, the left and right pages are saved as separate cards.
  • Click a screenshot card to show it in the main viewer. If there was a search term when it was captured, the original page is re-rendered with the highlight.
  • While showing screenshots, ◀ ▶ · page number · the right scrollbar · the mouse wheel move through the whole screenshot list, and the view combo switches page / width / custom zoom (fit page by default).
  • 💾 Save PDF or Ctrl+S (Tools → Save Screenshot PDF...): saves all screenshots into one PDF. In the options dialog choose ① highlight search terms (on = high-resolution re-render, off = original 1:1) ② file name at the top ③ page number at the bottom. Your choices become the defaults next time. After saving you are asked whether to load it in this window.
  • The screenshot list always starts empty; on exit, if it has cards, you are asked whether to save them as a PDF.

5. Build bookmarks automatically (Tools → Generate Bookmarks Automatically... / right-click a file → 'Build Bookmarks')

  • Analyzes the current PDF (or the file you right-clicked in the tree) and builds bookmarks.
  • Modes: Auto (TOC if present, otherwise font; OCR automatically for scanned images) · Force TOC · Force font · Scanned/Image (OCR). OCR mode recognizes headings such as 'CHAPTER 1' in scanned books, with an option to include large text as headings.
  • If several bookmarks land on the same page, only chapter titles (CHAPTER 1) and numbers (1, 1.1) are kept and the noise is removed.
  • Output: save as new PDF or save to current PDF (overwrite — you are warned if it already has bookmarks). A bookmark .txt for ALPDF can also be saved. When done, the bookmark list refreshes automatically (the existing file list is kept), and new PDFs in the same folder are added.

6. Editing bookmarks (the [Edit] button above the bookmark panel)

  • Turning Edit (pencil icon) on shows Cancel (undo every change since the last save) · Save and two rows of edit buttons. While editing, clicking a bookmark moves the main viewer there, and double-clicking opens the edit window. Right-click an item → Rename File/Bookmark / Delete File/Bookmark / Edit Bookmark... / Sort Selected Bookmarks by Page.
  • ◀ / ▶: outdent / indent. ▲ / ▼: move up / down. You can also drag with the mouse.
  • 🗑️ Delete (bookmark = remove from tree · file = Recycle Bin), ⭐ Keep Selected (delete everything else), 📋 Copy (copy the selected files to another folder), 💾 Save (<original>_edited.pdf). You can also add a bookmark at the current page by right-clicking the viewer.
  • If you turn editing off with unsaved changes, you are asked Save / Revert (Don't Save) / Keep Editing.

7. Sorting the bookmark tree

  • The sort combo under the search bar: Bookmarks (default) · Name · Modified · Size.
  • If there is a bookmarks.json, its order is used; the combo re-sorts immediately only in the flat (folder–PDF) mode.

8. Annotations — lines · shapes · text · photos · hyperlinks (edit mode)

  • In edit mode the annotation tools are added to the page toolbar. Pens 1–5 (Ctrl+1–5; colour · width · opacity) · Lines (double-click: Straight line / Highlight / Freehand, Ctrl+`) · Shape (Rectangle / Rounded Rectangle / Circle; ▾ No fill · Semi-transparent fill · Fill) · Text (text box ↔ Callout text; ▾ styles: Body · Title · Note · Emphasis) · Select objects (move · resize · delete; drag a box to select several) · Eraser (thin Ctrl+E / thick Ctrl+Shift+E) · Clear (all lines on this page, Ctrl+Shift+Backspace) · ↶ Undo (Ctrl+Z) / ↷ Redo (Ctrl+Y).
  • While typing, ▲▼ change the font size and ◀▶ the letter spacing. Move a selected object with the arrow keys (Shift = 1px); Del deletes it.
  • Right-click the page → Line and Text Input Settings…: set pens 1–5, highlight opacity and eraser size, and text styles (font · size · colour · letter spacing · box line · background · alignment · callout end), and save them.
  • Photos: right-click 'Insert Photo File' · 'Insert from Clipboard' (▼ Rectangle / Rounded Rectangle / Circle), Ctrl+V, or drop an image file. Ctrl+↑/↓ change a selected photo's opacity.
  • Add Hyperlink… (right-click the page or a thumbnail): give it a label and either a file (a document, image, video etc. in the bookmark folder) or an external link (URL) (https, allowed domains). It shows as a blue button on the page. Executables are blocked. Hyperlinks are kept in N-up printing and exports.
  • Saving: Save (for PolyPDF) (💾) = bookmarks and page edits go into the original PDF; annotations (lines, shapes, text, photos, hyperlinks) are kept next to it in page_meta.json and hyperlinks.json (shown in PolyPDF) · Save As... · Save (for other viewers)... = a new file (_for_other_viewers.pdf) with annotations, photos and hyperlinks flattened into the page so other PDF viewers show them (text stays searchable). There is also Tools → Save PDF Annotations.
  • If another PolyPDF window has the file open when you save, you are asked Close and Save / Save with New Name / Cancel.

9. Page editing (thumbnails, edit mode)

  • Order: drag a thumbnail, or Alt+↑/↓. Delete: the Delete key or right-click 'Delete'.
  • Rotate: right-click rotate left/right 90°. Hide: 'Hide / Unhide / Unhide All' (a hidden page shows a 'Hidden' band on the right).
  • Adding pages: 'Copy Selected Pages' (Ctrl+C) → 'Paste' (Ctrl+V, also into another PDF) · 'Paste Clipboard Photo as New Page' · drop image files or screenshot cards onto the thumbnails.
  • Page edits are applied with 💾 Save or 'Apply Changes — Save as New PDF...'.

10. Print · N-up · merge · images → PDF · encrypt

  • File → Print... (Ctrl+P): range (whole document · current page · selected thumbnails · selected bookmark files · page range · screenshots) · preview · printer · paper · print size (fit / actual size / scale) · colour (colour / black and white) · single/double-sided · include (Document + annotations / Document only) · copies. Print to PDF saves to a file.
  • N-up printing (the print dialog's 'N-up printing' → settings): 2·4·6·8 pages per sheet, fit mode, sides (single/double), gutter, facing pages (adds 1 blank page at the front), each document / odd page start, page numbers (position · font · background block), lines, cover · contents · divider pages (Word templates; samples can be saved). Save the settings as a style.
  • Merge PDFs (Tools → Merge PDFs..., Ctrl+M · right-click several files in the bookmark panel): joins the files in the order of the right-hand list. You can add the screenshot list too; there is a preview and options to reduce file size and make an N-up copy. When done it asks whether to open the result in a new window.
  • Convert Images → PDF...: picture list (top to bottom = page order, drag to reorder) · preview · save as N-up · save as PDF.
  • Encrypt (password · permissions)...: an open password, a permissions password (what printing, changes and copying are allowed), 256-bit AES (recommended) / 128-bit AES. Open an encrypted file with right-click 'Enter Password' in the bookmark panel.

11. Text pane · OCR

  • 📄 Text tab (View → Text): shows the text of the current page (in Continuous mode, the page in the middle of the screen). Styles (font · size · bold · letter spacing · line spacing for titles and body), Skip tables, Join sentences.
  • You can fix the text line by line; selecting a line marks that spot on the page. Highlight · Show in body too · To bookmarks (turn highlighted spots into bookmarks) · Save Word ▾ (current page / page range / whole document).
  • Read with OCR (OCR toolbar button · Tools menu · text pane): reads the text of scanned PDFs — current page / page range / whole document, language, 'Ignore background watermarks', 'Skip pages that already have text'. Apply to PDF writes the text layer into the PDF (the original is backed up). Get the OCR engine from Tools → Install Components (recording · OCR)….

12. Presentation · recording (F5)

  • Presentation (F5 · toolbar · View menu · page right-click): full screen. Move the mouse to the top of the screen for the top bar (page · pens 1–N · line type · partial erase · clear · Apply to Main View · Open Links · ⏱ presentation timer · ● record · ✕ exit), and to the left edge for thumbnails.
  • Mouse: left-drag = draw, click in the left 10% = previous page, click elsewhere = next page. Keys: → Space PgDn ↓ next · ← PgUp ↑ previous · Home/End · digits + Enter go to a page · S top/bottom split · D two pages · Esc exits. At the last page it moves on to the next file.
  • Right-click: pointers and Pointer Settings, pens and Line Settings, Clear Lines, Top/Bottom Split View (centre overlap %), Two-Page View (facing pages), Fill Screen, View Settings (cropping), Presentation Timer Settings (preparation text · duration · alarms), Start Recording with Timer, and the screen (monitor).
  • With 'Apply to Main View' on, when you finish you are asked where to keep the lines you drew: the main view, a PDF, or both.
  • Recording (Ctrl+R record/resume, Ctrl+Shift+R stop): screen + audio to mp4. In Settings → Screen + Audio Recording choose the save location · audio (video only / microphone / system sound / microphone + system) · devices · shortcuts, and check with Test Recording (3 s). ffmpeg is installed from Install Components.

13. Favorites · file tags

  • Favorites menu: add the current folder, file or search, and reorder, rename or delete them in Manage Favorites.... You can also add from the bookmark panel's right-click menu.
  • Hashtags: tag a file with right-click Edit Hashtags..., then pick tags by type and topic from the # button in the bookmark panel to search with #tag.
  • Automatic tagging (Settings 'Auto-assign file hashtags/keywords', off by default): after indexing, tags are added from the content (shown as ·#). The 🏷️ section of the Tools menu has Recalculate Tags · Review New Tag Candidates · Undo Last Automatic Tagging · Delete All Automatic Tags · Clean Up Missing File Entries.

15. Settings (Tools → Settings...)

  • Language (top of the window): Korean / English — applied after restarting. Use external language packs.
  • On startup: open the last folder/file / a chosen folder/file / a blank screen · open the last viewed page · automatic hashtags · PolyPDF startup mode (edit / view).
  • Screenshot limit (5–1000; raised automatically for batch captures)
  • Panel toolbar: show the top panel toolbar · go to the next/previous file from the last/first page · page navigation · page-turn animation.
  • Hyperlinks: top offset of the buttons on the page. Screen + Audio Recording (§12). Appearance: auto (system) / light / dark.
  • Tools menu: Keyboard Shortcuts... · Save Current Settings as Defaults (for distribution)… · Reset Settings (restore defaults)….

16. Help · updates · components

  • Open this guide any time from Help → User Guide.
  • Version, copyright, license (GNU AGPL v3) and open-source notices are in Help → About.
  • Check for Updates: if a new version is available, it shows what changes in each version. Pressing [Update] downloads the file first, then closes all open PolyPDF windows and installs (if you cancel the download or it fails, nothing is closed). Download Updates Automatically (on by default) fetches new versions in advance. Also Receive Beta (Test) Versions is always on before 1.0.
  • Tools → Install Components (recording · OCR)…: downloads ffmpeg for recording and the OCR engine (installed ✓ / not installed).
