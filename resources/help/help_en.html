Using PolyPDF

1. Getting started

  • File → Open Folder (Ctrl+O) — choose a folder that contains PDFs. If the folder has a bookmarks.json, it is shown as a bookmark tree; otherwise all PDFs are listed in a flat tree.
  • File → Open File (Ctrl+Shift+O) — open a single PDF.
  • You can also drag and drop a PDF file or folder onto the window.
  • The first time you open a folder, its text is indexed in the background (progress in the status bar).

2. Screen layout

  • Bookmarks panel (left): click to load the file in the main viewer. Expand a file node (▸) to see the PDF's own bookmarks (TOC). Right-click a file or bookmark for more (open file location, save as, save for PolyPDF, save for other viewers, rename or delete files and bookmarks, build bookmarks, and so on).
  • Expand All Bookmarks (right-click): expands the bookmarks of every file visible in the panel. While it is on (checked in the menu), files that appear as you scroll or as the list changes are expanded too. Collapse All Bookmarks turns this off and collapses back to the file rows.
  • Page thumbnails (second column): every page of the current PDF. Click to jump. Right-click a thumbnail → 'Add Bookmark' (to the current file in the tree).
  • Main viewer (center): toolbar = ‹ [page] /N › · zoom −/+ · screen capture · read aloud ▶ + range ▾ (once/continuous/all/all continuous · speed · voice) · mp3 (save the current PDF split by bookmarks) · view combo (page / 2 pages / width / custom zoom). The vertical scrollbar on the right shows your progress through the whole document (drag to move).
  • Split view (Ctrl+2): splits the main viewer into two panes so you can view two PDFs at once. Click a pane to make it active (blue border); bookmarks, search, thumbnails and reading then work on the active pane, and each pane's 📷 capture, read and mp3 buttons work on that pane alone.
  • Sliding panel: in split view, or when search and screenshots are both hidden, the right panel becomes a slide-out drawer that you open with the edge handle (‹) (it opens briefly during a capture and closes after 1.5 seconds). With only screenshots on, it shows as a grid.
  • Text · search · screenshots (right): text and search tabs (top) + screenshots (bottom). Toggle them from the toolbar's View buttons. When all screenshots are deleted, the screenshot area hides itself.

2-1. Read aloud (TTS) · mp3

  • Toolbar ▶ = read the body text from the current page / stop (headers, tables, formulas and figures are skipped). The sentence being read is highlighted in light blue, and pages follow automatically. Click a sentence to read from there.
  • Range ▾: once / continuous / all / all continuous, plus speed and voice.
  • Toolbar mp3 (MP3 icon): saves the current PDF as mp3 files (+ .lrc lyrics), split by bookmark level (1/2/3) (one file if there are no bookmarks).

3. Search

  • Type in the search bar at the top right and press Enter. Matches are highlighted in the text.
  • Sort results: by name (bookmark order) / by match count.
  • F3 / Shift+F3 or the search bar's ▶ / ◀: next / previous match. After the last match in a file, it jumps to the first match of the next file in the results.
  • Save: save the results to Excel (.xlsx) (the file name gets a date-time prefix).
  • Capture all: take screenshots of every matching page in the results. If there are more results than the limit, the limit is raised automatically.

4. Screenshots / screen capture

  • Capture with the main toolbar's 📷 capture button or Ctrl+Shift+S. Choose the mode from the drop-down next to the capture icon: Full screen (current page / selected thumbnails) · Region (drag a box on the screen, move or resize it, then press Enter or double-click to capture) · Custom size 1–5 (a box of a set size at the point you click; set names and pixel sizes in 'Custom Size Settings'). Capture quality (as shown / original quality).
  • Select several thumbnails and capture to save each page full screen in one go.
  • Each screenshot card shows its order number underneath (updated when you reorder or delete).
  • Copy to Clipboard (📋): copies the screenshots to the clipboard in order → paste them one by one from the Win+V list.
  • Import from Clipboard (📥): adds the picture on the clipboard (copied from a capture tool, or image files copied in File Explorer) as screenshot cards.
  • In 2-page view, the left and right pages are saved as separate cards.
  • Click a screenshot card to show it in the main viewer. If there was a search term when it was captured, the original page is re-rendered with the highlight.
  • While showing screenshots, ◀ ▶ · page number · the right scrollbar · the mouse wheel move through the whole screenshot list, and the view combo switches page / width / custom zoom (fit page by default).
  • 💾 Save PDF or Ctrl+S: saves all screenshots into one PDF. In the options dialog choose ① highlight search terms (on = high-resolution re-render, off = original 1:1) ② file name at the top ③ page number at the bottom. Your choices become the defaults next time. After saving you are asked whether to load it in this window.

5. Build bookmarks automatically (Tools → Generate Bookmarks Automatically... / right-click a file → 'Build Bookmarks')

  • Analyzes the current PDF (or the file you right-clicked in the tree) and builds bookmarks.
  • Modes: Auto (TOC if present, otherwise font; OCR automatically for scanned images) · Force TOC · Force font · Scanned/Image (OCR). OCR mode recognizes headings such as 'CHAPTER 1' in scanned books, with an option to include large text as headings.
  • If several bookmarks land on the same page, only chapter titles (CHAPTER 1) and numbers (1, 1.1) are kept and the noise is removed.
  • Output: save as new PDF or save to current PDF (overwrite — you are warned if it already has bookmarks). A bookmark .txt for ALPDF can also be saved. When done, the bookmark list refreshes automatically (the existing file list is kept), and new PDFs in the same folder are added.

6. Bookmark edit mode (the [✎ Edit] button above the bookmark tree)

  • Edit (pencil icon) toggle: single/tree buttons appear next to it. While editing, clicking a bookmark moves the main viewer there, and double-clicking opens the edit window. Right-click an item → rename or delete files and bookmarks.
  • ◀ / ▶: outdent / indent. ▲ / ▼: move up / down. You can also drag with the mouse.
  • ✎ edit one item (title · page / file name), 🗑️ delete (bookmark = remove from tree · file = Recycle Bin), ⭐ keep selected, 📋 copy, ➕ page (bookmark at the current page), 💾 save (<original>_edited.pdf). You can also add a bookmark at the current page by right-clicking the viewer.
  • If you turn editing off with unsaved changes, you are asked whether to save.

7. Sorting the bookmark tree

  • The sort combo under the search bar: Bookmarks (default) · Name · Modified · Size.
  • If there is a bookmarks.json, its order is used; the combo re-sorts immediately only in the flat (folder–PDF) mode.

9. Settings

  • Restore the last session on startup / open the last viewed page
  • Restore the screenshot list on startup
  • Screenshot list limit (5–1000; raised automatically for batch captures)
  • Panels: search results / screenshots — turning both off switches to the slide-out drawer.
  • Theme: auto (system) / light / dark.
  • Language: Korean / English — applied after restarting.
  • Keyboard shortcuts: view, change and restore all shortcuts.

10. Help / About

  • Open this guide any time from Help → User Guide.
  • Version, copyright, license (GNU AGPL v3) and open-source notices are in Help → About.
  • Check for Updates: if a new version is available, it shows what changes in each version. Pressing [Update] downloads the file first, then closes all open PolyPDF windows and installs (if you cancel the download or it fails, nothing is closed).
