Using PolyPDF

1. Getting started

  • File → Open Folder (Ctrl+O) — choose a folder that contains PDFs. If the folder has a bookmarks.json, it is shown as a bookmark tree; otherwise all PDFs are listed in a flat tree.
  • File → Open File (Ctrl+Shift+O) — open a single PDF. Favorites → Recent Folders / Recent Files reopen what you opened before.
  • You can also drag and drop a PDF file or folder onto the window.
  • If you open several PDFs at once from File Explorer they gather in one window; files opened later open in a new window.
  • The first time you open a folder, its text is indexed in the background (progress in the status bar). If search results look out of date, use Tools → Rebuild Index.
  • Edit mode / view mode: switch with the Edit button above the bookmark panel (blue pencil = view, red pencil = edit). The mode at startup is PolyPDF startup mode under 'On startup' in Settings.
  • Tools → Register & Install → Set as Default PDF App…: adds PolyPDF to the 'Open with' list (choosing it as the default is done in Windows Settings — the dialog shows how).

2. Screen layout

  • Bookmarks panel (left): click to load the file in the main viewer. Expand a file node (▸) to see the PDF's own bookmarks (TOC). Along the top: the Search list names box · # (hashtags, §13) · Sort (§7) · 📁 Folder (file mode ↔ folder mode) · Tree (single ↔ tree) · ↻ (refresh after files change outside — also in edit mode; asks first if there are unsaved changes).
  • Right-click a file or bookmark: Open in File Explorer · New Folder · Rename File/Bookmark · Delete File/Bookmark / Save · Save As · Flatten and Export / Split View · Expand/Collapse All Bookmarks / Build Bookmarks · Edit Hashtags · add to Favorites, and so on. In edit mode there are also Copy Files / Move Files (below New Folder), rename / delete folder, and merging several files.
  • Expand All Bookmarks (right-click): expands the bookmarks of every file visible in the panel. While it is on (checked in the menu), files that appear as you scroll or as the list changes are expanded too. Collapse All Bookmarks turns this off and collapses back to the file rows.
  • Page thumbnails (second column): every page of the current PDF. Click to jump. Filter with the buttons on top: All · Shown (pages not hidden) · Marked (pages with lines, shapes, text or photos) · Hidden. Right-click a thumbnail → 'Add Bookmark' (to the current file in the tree) · print · copy to screenshots · page editing (§9).
  • Main viewer (center): toolbar = ‹ [page] /N › · zoom −/+ · screen capture · read aloud ▶ + Range ▾ · mp3 · view combo (page / 2 pages / width / custom zoom). In edit mode the annotation tools (§8) follow. The vertical scrollbar on the right shows your progress through the whole document (drag to move). Right-click the page (or Shift+F10): Print… (print window, current page) · Copy (this page) · Copy Text · Copy Text After Selecting a Block · Split View (in split view: Single View · Open in Other Pane) · Presentation · rotate 90° · Sign Here…. In edit mode also Paste · Paste Screenshots · Paste from Clipboard · Paste Photo · Delete · Save · Hide/Unhide · Add Bookmark · Add Hyperlink · Shape/Text Input Settings. In edit mode, pressing Del with no object selected deletes this page (until you save). Menus show each item's shortcut on the right. Paste uses what you copied last — copied pages go below this page, copied objects go where you clicked. Paste from Clipboard pastes pages and pictures as a picture and text as a text box.
  • Menu tabs: click Quick Access · File · Favorites · View · Tools · Help at the top of the window and the tab's commands appear in one row below it (Alt+C·F·V·B·T·H also switch tabs). Quick Access holds the buttons you use most and is shown at start; add, remove or reorder them with Manage Quick Access... in Settings or by right-clicking the tab bar (Alt+C opens the tab). Turn off Show Ribbon there and the ribbon only appears briefly when you click a tab. The search box is at the right end of the tab row.
  • View buttons (Quick Access · View tab): Single (hide the right panel) · Split · Text · Search · Screenshots · Presentation (§12).
  • Split View (Ctrl+Shift+2): splits the main viewer into two panes so you can view two PDFs at once. Click a pane to make it active (blue border); bookmarks, search, thumbnails and reading then work on the active pane, and each pane's 📷 capture, read and mp3 buttons work on that pane alone. Right-click 'Open in Other Pane' opens the same document and page in the other pane. Saving in one pane leaves the other pane on its file and page.
  • Sliding panel: in split view, or when search and screenshots are both hidden, the right panel becomes a slide-out drawer that you open with the edge handle (‹) (it opens briefly during a capture and closes after 1.5 seconds). With only screenshots on, it shows as a grid.
  • Right panel: top = 📄 Text · 🔎 Search tabs, bottom = screenshots. When all screenshots are deleted, the screenshot area hides itself.

2-1. Read aloud (TTS) · mp3

  • Toolbar ▶ = read the body text from the current page / stop (headers, tables, formulas and figures are skipped). The sentence being read is highlighted in light blue, and pages follow automatically. Click a sentence to read from there.
  • Range ▾: Once / Continuous / All / Full, continuous, plus speed (Slow · Normal · Fast · Very fast) and voice (auto picks one per language).
  • Toolbar mp3 (MP3 icon): saves the current PDF as mp3 files (+ .lrc lyrics), split by bookmark level (1/2/3) (one file if there are no bookmarks).

2-2. Turning pages (wheel · trackpad · keyboard)

  • Wheel: a zoomed page scrolls inside the page first; at the edge, scroll a little more to go to the next page. With fit page, one notch = one page. Trackpad momentum never turns the page. Ctrl+wheel = zoom.
  • Page navigation (Settings): Single page (default; 'Page-turn animation' on or off) / Continuous (adjacent pages joined, smooth scrolling — the page in the middle of the screen is the current page). 2-page view and the screenshot view always go one page at a time.
  • Light page turning (Settings, automatic by default): turns on by itself when the Windows power mode is 'Best power efficiency' or battery saver, or when page turning is slow, and the status bar shows 🔋 Light page turning. The page-turn animation is off, pages in between are skipped when you turn several in a row, the Text pane follows once you stop, and the next pages are drawn in advance. Heavy jobs such as OCR or conversion then tell you that they may take longer.
  • Go to next/previous file from last/first page (Settings, on by default): scrolling past the end shows the first (last) page of the next (previous) PDF and asks whether to open it. Choosing a file in the bookmark panel never asks.
  • Keyboard: PgUp/PgDn one page · ↑/↓/Space (Shift+Space back) move inside the page first, then to the next page · Home/End first/last page · Ctrl+C copy text.

3. Search

  • Type in the search bar at the top right and press Enter. Matches are highlighted in the text. Next to the search box, Aa = match case and .* = regular expression (e.g. \d{4}-\d{2}) — the result list, highlights and F3 all follow the same rule.
  • Search ignores spaces and line breaks — it finds words split at the end of a line or typed with different spacing. For scanned PDFs, it searches the OCR text once you save it (that file is indexed again after saving).
  • Sort results: Bookmarks / Name / Matches.
  • F3 / Shift+F3 or the search bar's ▶ / ◀: next / previous match. After the last match in a file, it jumps to the first match of the next file in the results.
  • Filter by #tag: choose tags from the # button in the bookmark panel and #tag is added to the search (§13).
  • Save: save the results to Excel (.xlsx) (the file name gets a date-time prefix).
  • Capture all: take screenshots of every matching page in the results. If there are more results than the limit, the limit is raised automatically.
  • Keep searches you use often with Favorites → Add Current Search.

4. Screenshots / screen capture

  • Capture with the main toolbar's 📷 capture button or Ctrl+Shift+S. Choose the mode from the drop-down next to the capture icon: Full screen (current page / selected thumbnails) · Region capture (press and drag a box on the screen, move or resize it by dragging or with the arrow keys, then press Enter or double-click to capture · right-click to pick again · Enter at the start reuses the last region) · Custom size 1–5 (a box of a set size at the point you click; set names and pixel sizes in 'Custom Size Settings'). Capture quality (as shown / original quality). In Keyboard Shortcuts you can make screen capture a global shortcut (works over other programs).
  • Select several thumbnails and capture to save each page full screen in one go (the thumbnail right-click 'Copy to Screenshots' does the same).
  • Each screenshot card shows its order number underneath (updated when you reorder or delete). Drag cards to reorder; right-click 'Delete' (or 'Delete n selected') · 🗑 Delete All. In edit mode, drop a card onto the thumbnails to insert it as a new page.
  • Copy to Clipboard (📋, Ctrl+Shift+C): copies the screenshots to the clipboard in order → paste them one by one from the Win+V list.
  • Import from Clipboard (📥): adds the picture on the clipboard (copied from a capture tool, or image files copied in File Explorer) as screenshot cards.
  • In 2-page view, the left and right pages are saved as separate cards.
  • Click a screenshot card to show it in the main viewer. If there was a search term when it was captured, the original page is re-rendered with the highlight.
  • While showing screenshots, ◀ ▶ · page number · the right scrollbar · the mouse wheel move through the whole screenshot list, and the view combo switches page / width / custom zoom (fit page by default).
  • 💾 Save PDF or Ctrl+Alt+S: saves all screenshots into one PDF. In the options dialog choose ① highlight search terms (on = high-resolution re-render, off = original 1:1) ② file name at the top ③ page number at the bottom. Your choices become the defaults next time. After saving you are asked whether to load it in this window.
  • The screenshot list always starts empty; on exit, if it has cards, you are asked whether to save them as a PDF.

5. Build bookmarks automatically (Tools → Generate Bookmarks Automatically... / right-click a file → 'Build Bookmarks')

  • Analyzes the current PDF (or the file you right-clicked in the tree) and builds bookmarks.
  • Modes: Auto (TOC if present, otherwise font; OCR automatically for scanned images) · Force TOC · Force font · Scanned/Image (OCR). OCR mode recognizes headings such as 'CHAPTER 1' in scanned books, with an option to include large text as headings.
  • If several bookmarks land on the same page, only chapter titles (CHAPTER 1) and numbers (1, 1.1) are kept and the noise is removed.
  • Scanned books too: it finds the table of contents pages (first 15 pages) and follows them. Pages already OCR'd (Text panel 'Read Again with OCR') are not read again, and newly read pages show in the Text panel right away.
  • Result: nothing is written to the PDF yet — the bookmarks go into that file in the Bookmarks panel unsaved (edit mode); check them and press [Save] to write them to the PDF. A bookmark .txt for ALPDF is created right away if you choose it.
  • Review table: Del = delete selected rows, [Edit Title] = edit the current row's title, [OK] = put them in the Bookmarks panel.
  • If it takes long, click the progress bar in the status bar and press [Stop] in the Tasks window. Pages already read are kept, so building again continues; the stop window lets you open the review table with what was found so far or discard the OCR results too.
  • OCR results are kept only when saved — use the status bar '💾 Unsaved OCR' button, the Bookmarks panel [Save], or the prompt on exit.

6. Editing bookmarks (the [Edit] button above the bookmark panel)

  • Turning Edit (pencil icon) on shows Cancel (undo every change since the last save) · Save and two rows of edit buttons. While editing, clicking a bookmark moves the main viewer there, and double-clicking opens the edit window. Right-click an item → Rename File/Bookmark / Delete File/Bookmark / Edit Bookmark... / Sort Selected Bookmarks by Page. Changing bookmarks (rename, delete, add, build automatically) works only in edit mode — in view mode you are asked whether to turn edit mode on (renaming or deleting files works any time). In split view, new bookmarks go into that bookmark panel; if both panels show the same file, both change.
  • ◀ / ▶: outdent / indent. ▲ / ▼: move up / down. You can also drag with the mouse.
  • 🗑️ Delete (bookmark = remove from tree · file = Recycle Bin), Shift + 🗑️ Delete (keep only the selected bookmarks and delete the file's others, after confirming), 📋 Copy (copy the selected files to another folder), 💾 Save (<original>_edited.pdf). You can also add a bookmark at the current page by right-clicking the viewer.
  • If you turn editing off with unsaved changes, you are asked Save / Revert (Don't Save) / Keep Editing.

7. Sorting the bookmark tree

  • The sort combo under the search bar: Bookmarks (default) · Name · Modified · Size.
  • If there is a bookmarks.json, its order is used; the combo re-sorts immediately only in the flat (folder–PDF) mode.

8. Annotations — lines · shapes · text · photos · hyperlinks (edit mode)

  • In edit mode the annotation tools are added to the page toolbar. Pens 1–5 (Ctrl+1–5; colour · width · opacity) · Lines (double-click: Straight line / Highlight / Freehand, Ctrl+`) · Shape (Rectangle / Rounded Rectangle / Circle; ▾ No fill · Semi-transparent fill · Fill) · Text (text box ↔ Callout text; ▾ styles: Body · Title · Note · Emphasis) · Select objects (move · resize · delete; drag a box to select several) · Eraser (thin Ctrl+E / thick Ctrl+Shift+E) · Clear (all lines on this page, Ctrl+Shift+Backspace) · ↶ Undo (Ctrl+Z) / ↷ Redo (Ctrl+Y) — undoes what you did in edit mode (decorations, photos, bookmarks, moving/deleting/splitting pages, hiding, rotation, hyperlinks, crop) in order, from anywhere in the window and across pages.
  • While typing, ▲▼ change the font size and ◀▶ the letter spacing. Move a selected object with the arrow keys (Shift = 1px); Del deletes it.
  • Right-click on a selected object: with a text box, line or photo selected, the right-click menu shows only its options (Line and Text Input Settings… opens on the Text tab for a text box). The crop and digital signature buttons appear only in edit mode.
  • Copy and paste: Ctrl+C → Ctrl+V copies selected text boxes, lines, shapes and photos (several selected with a box, too) — slightly offset on the same page, at the same place on another page or file. Right-click 'Copy' / 'Paste' pastes where you clicked. Drag with Shift held to move a copy and leave the original.
  • Right-click the page → Shape Input Settings… / Text Input Settings…: set pens 1–5, highlight opacity and eraser size, and text styles (font · size · colour · letter spacing · box line · background · alignment · callout end), and save them.
  • Photos: right-click 'Paste Photo' · 'Paste from Clipboard' (▼ Rectangle / Rounded Rectangle / Circle) · 'Paste Screenshots' (selected screenshots, or all), Ctrl+V, or drop an image file. Ctrl+↑/↓ change a selected photo's opacity.
  • Add Hyperlink… (right-click the page or a thumbnail): give it a label and either a file (a document, image, video etc. in the bookmark folder) or an external link (URL) (https, allowed domains). It shows as a blue button on the page. Executables are blocked. Hyperlinks are kept in N-up printing and exports.
  • Save (💾) = bookmarks, page edits, rotation and crop go into the original PDF, and annotations (lines, shapes, text, photos), hyperlinks and tags are also put into the PDF so other PDF viewers show them (a 'PolyPDF' layer you can hide in another viewer's layer panel). Keep editing in PolyPDF and save again. Signed documents do not get the annotation copy · Save As... · Flatten and Export... = a new file (_flattened.pdf) with annotations, photos and hyperlinks flattened into the page and the content outside a crop really removed (text stays searchable; the original is untouched). Use it for programs that ignore annotations, for submissions, or to remove cropped-out content. Signed documents are signed again at the same places (your digital ID is confirmed — cancel and that signature is left out).
  • If another PolyPDF window has the file open when you save, you are asked Close and Save / Save with New Name / Cancel.

9. Page editing (thumbnails, edit mode)

  • Order: drag a thumbnail, or Alt+↑/↓. Delete: the Delete key or right-click 'Delete'.
  • Rotate: right-click rotate left/right 90°. Hide: 'Hide / Unhide / Unhide All' (a hidden page shows a 'Hidden' band on the right).
  • Adding pages: 'Copy' (Ctrl+C) → 'Paste' (Ctrl+V, also into another PDF) · 'Paste Screenshots' (all screenshot cards as new pages) · 'Paste from Clipboard' · drop image files or screenshot cards onto the thumbnails. 'Insert New Page' adds a white page the size of the clicked thumbnail's page below it — you can add photos, lines and text right away; press 💾 Save to keep it.
  • Crop and split pages (crop button to the right of '+' on the page toolbar): margins up to 95% per side (opposite sides together up to 95%). Split Pages — 2 pages left/right, 2 pages top/bottom or 4 pages: the area left after cropping is split at the split lines (centre by default; drag the blue lines in the preview to adjust), turning one page into 2 or 4. 'Right part first' is for books read right to left. Split pages show at once in the thumbnails and the main view and go into the original only when you press 💾 Save (Cancel reverts).
  • Drag to copy into another file: drag thumbnails (several allowed) or screenshot cards and rest over another file or bookmark in the bookmark panel — that file opens. Move over the thumbnails and drop on the thumbnail you want — the pages are copied below it (applied with 💾 Save). Another file is not opened while there are unsaved edits.
  • Page edits are applied with 💾 Save or 'Apply Changes — Save as New PDF...'.

10. Print · N-up · merge · images → PDF · encrypt

  • File → Print... (Ctrl+P): range (whole document · current page · selected thumbnails · selected bookmark files · page range · screenshots) · preview · printer · paper · print size (fit / actual size / scale) · colour (colour / black and white) · single/double-sided · include (Document + annotations / Document only) · copies. Print to PDF saves to a file.
  • Create N-up PDF... (Tools → Create N-up PDF...): turns the PDF open in the viewer into a new N-up file (1-up included). Same settings and styles as N-up printing, without the multi-file items such as dividers or a new page per document. The table of contents lists the top-level bookmarks; bookmarks are carried over as they are.
  • N-up printing (the print dialog's 'N-up printing' → settings): 1·2·4·6·8 pages per sheet, fit mode, sides (single/double), gutter, facing pages (adds 1 blank page at the front), each document / odd page start, page numbers (position · font · background block), lines, cover · contents · divider pages (Word templates; samples can be saved). Save the settings as a style.
  • Convert (File and Tools tabs 'Convert' · bookmark panel right-click 'Convert...' · thumbnail right-click 'Convert selected pages'): turns the PDF into Word, Hangul HWPX, PowerPoint, Excel (tables), text or images. Both Word/HWPX modes give editable text — editable joins broken lines into paragraphs; keep appearance keeps the original lines, indents, spacing, font sizes and letter spacing so it looks like the original. On a PC with Word installed you can also choose Word (using Microsoft Word), which lets Word do the conversion. Pictures stay pictures; captions are text; running headers and footers go into the format's own header/footer (page numbers become automatic page numbers — Hangul's page numbering). Saved next to the PDF with the same name; if that name exists, (2) is added. Choose the whole document, a page range or the selected pages; select several files in the bookmark panel to convert them together.
  • Merge PDFs (Tools → Merge PDFs..., Ctrl+M · right-click several files in the bookmark panel): joins the files in the order of the right-hand list. You can add the screenshot list too; there is a preview and options to reduce file size and make an N-up copy. When done it asks whether to open the result in a new window.
  • Convert Images → PDF...: picture list (top to bottom = page order, drag to reorder) · preview · save as N-up · save as PDF.
  • Encrypt (password · permissions)...: an open password, a permissions password (what printing, changes and copying are allowed), 256-bit AES (recommended) / 128-bit AES. Open an encrypted file with right-click 'Enter Password' in the bookmark panel.

10-1. Digital signature (button to the right of Crop on the page toolbar · Tools → Digital Signature ▸)

  • Signature Image...: load a photo of your signature on paper (or a transparent PNG). The background is removed, you pick the ink color (Original · Black · Blue), and it is cropped to the signature and saved under a name. An image on the clipboard works too.
  • Digital IDs...: create a new digital ID (name · email · validity · password) or import an existing .pfx/.p12. After creating one, use Export Backup to keep the .pfx somewhere safe — if the PC fails you cannot sign with the same ID again. Give the public certificate (.cer, Export Public Certificate) to the people who receive your documents. Import Korean Certificate (NPKI)… finds Korean certificates in NPKI folders on the PC or a USB drive and imports one with its certificate password (the original folder is unchanged; the password stays the same). From Windows Certificate Store… uses a certificate held by Windows (including smart cards and USB tokens) without copying the key — Windows may ask for a PIN when you sign.
  • Signing — place, then confirm once: press the digital signature button to the right of Crop (or Tools → Sign...) and drag on the page where the signature image goes (a single click uses the default size). Right-click → Sign Here… places one with the default size at that spot. Dragging does not sign yet — it makes a signature place (dashed box): drag it to move, use the bottom-right corner to resize (keeps the image ratio; hold Shift for free), press Delete to remove. You can put several on one page. Its right-click menu offers 'Image only (not a digital signature)' and 'Place on Other Pages…'. Drawing tools of edit mode are turned off when you press the signature button. When done, press Confirm Signatures… in the band above the page, choose the digital ID, signature image and appearance text (name · date · reason), then Sign with Windows Hello or enter the password and press Confirm Signatures. All places are signed at once into a new file 'name_signed.pdf'; the original stays unchanged. You cannot place signatures in two-page view. Rotated pages are signed in the text direction.
  • Changing a signature: a signed file shows Edit Signatures in the band above the page (for signatures made with your digital ID). It turns the signatures back into places — move, resize or delete them, then Confirm Signatures… replaces that signed file. It is not possible when someone else's signature comes after yours.
  • Image only: Tools → Insert Image Only... puts only a registered signature image, without a digital signature (the image has no signature effect). Placing and confirming work as for signatures.
  • More choices in the signing window: Signature type — approval signature (default) or certification (no changes / form filling and signing allowed / comments, forms and signing allowed; only as the document's first signature) · Text layout — image above, text below (default — the image fills the dragged box, the text goes below it and wraps so it is never cut off) / over the image / image left, text right · Timestamp — enter a timestamp authority (TSA) address and turn it on to add the authority's time (internet needed, off by default). The signature image window also offers Draw by Hand….
  • Empty signature fields: Tools → Create Empty Signature Field... lets you drag a place on the page and name it (e.g. Approver); the recipient then signs in that field. A document with empty fields shows 'empty signature field' in the band above the page, and the signature button offers Sign in an empty field (dragging inside a field or right-clicking in it also signs that field). A document certified by its author can be signed only in its empty fields. When creating a field you can designate the signer by that person's public certificate (.cer), and Lock all fields in the document when this field is signed prevents any further change or signature after that signature (use it on the last signature field).
  • Password: on a PC with Windows Hello (fingerprint · PIN) the password is locked with Windows Hello when you create the ID, and signing only asks for Windows Hello. Without Windows Hello, keep the password in a password manager such as Google Password Manager and paste it (Ctrl+V). PolyPDF never stores the password in plain text.
  • Checking signatures: a signed document shows a band above the page — ✅ Valid · Trusted / ⚠ Valid · Identity unknown / ⚠ Changed after signing / ❌ Invalid. Signatures shows the signer, time and certificate fingerprint; Trust This Certificate adds it (only after confirming the fingerprint with that person). Save Signed Version… saves the file exactly as it was when that signature was made.
  • Saving after signing: saving the file again in PolyPDF (bookmarks, page edits, crop and so on) breaks the signature, so you are asked to save to a new file. If there are unsaved edits or annotations not yet in the PDF, you are asked [Save and Sign] — only the saved version is covered by the signature.
  • Good to know: a self-created digital ID shows as 'identity unknown' in the recipient's PDF viewer until they trust your public certificate (.cer). Changes after signing are detected even without trusting it. The signing time comes from the signing PC's clock. Where a specific certificate is required, a self-created ID cannot replace it — import that certificate and sign with it.

11. Text pane · OCR

  • 📄 Text tab (View → Text): shows the text of the current page (in Continuous mode, the page in the middle of the screen). Styles (font · size · bold · letter spacing · line spacing for titles and body), Skip tables, Join sentences.
  • You can fix the text line by line; selecting a line marks that spot on the page. Highlight · Show in body too · To bookmarks (turn highlighted spots into bookmarks) · Save Word ▾ (current page / page range / whole document).
  • Read with OCR (Quick Access 'OCR' · Tools tab · text pane): reads the text of scanned PDFs — current page / page range / whole document, language, 'Ignore background watermarks', 'Skip pages that already have text'. Apply to PDF writes the text layer into the PDF (the original is backed up). Get the OCR engine from Tools → Register & Install → Install Components….
  • Create OCR text layer (select several files or a folder row in the bookmark panel and right-click): reads the scanned pages without a text layer in all selected PDFs with OCR at once and adds an invisible text layer to the originals — other programs can then search and copy the text. A backup is kept next to the original the first time, pages already read are not read again, and signed or password-protected PDFs are skipped.
  • Reduce size and export (bookmark panel right-click — several files or a folder row too): lowers only image resolution and quality (light 200 · medium 150 · strong 100 dpi) and saves a smaller new file <name>_compressed.pdf. Text and the original stay as they are; no file is made unless it shrinks by more than 5%.
  • Remove personal data and save separately (bookmark panel right-click): in the redaction window, drag on the page to choose areas, or find resident registration, phone, email, card and business numbers or a search term (scanned pages use the OCR results). A new file <name>_redacted.pdf is made with the text and images in those places actually removed, and hidden data such as document info and attachments is removed too. The original stays.
  • Compare two files (select two files in the bookmark panel and right-click): split view shows the older file (modified earlier) on the left and the newer on the right, with deleted lines in red, inserted lines in green and changed lines in yellow. Click an item in the change list to move both panes to it; closing the list clears the colors.

12. Presentation · recording (F5)

  • Presentation (F5 · Quick Access · View tab · page right-click): full screen. Move the mouse to the top of the screen for the top bar (page · pens 1–N · line type · partial erase · clear · Apply to Main View · Open Links · ⏱ presentation timer · ● record · ✕ exit · 🖥 Main/Other Screen), and to the left edge for thumbnails. Lines, shapes, text and photos added in the main view are shown too.
  • Mouse: left-drag = draw, click in the left 10% = previous page, click elsewhere = next page. Keys: → Space PgDn ↓ next · ← PgUp ↑ previous · Home/End · digits + Enter go to a page · S top/bottom split · D two pages · Esc exits. At the last page it moves on to the next file.
  • Right-click: pointers and Pointer Settings, pens and Line Settings, Clear Lines, Top/Bottom Split View (centre overlap %), Two-Page View (facing pages), Fill Screen, View Settings (cropping), Presentation Timer Settings (preparation text · duration · alarms), Start Recording with Timer, and the screen (monitor).
  • 🖥 To Screen 2 / 🖥 To Main Screen (where a click takes you) at the far right of the top bar moves the presentation to another monitor or back to the viewer's monitor. The choice is remembered for the next presentation (disabled with a single monitor).
  • With 'Apply to Main View' on, when you finish you are asked where to keep the lines you drew: the main view, a PDF, or both.
  • Recording (Ctrl+R record/resume, Ctrl+Shift+R stop): screen + audio to mp4. In Settings → Screen + Audio Recording choose the save location · audio (video only / microphone / system sound / microphone + system) · devices · shortcuts, and check with Test Recording (3 s). ffmpeg is installed from Install Components.

13. Favorites · file tags

  • Favorites tab: add with Add Current Folder · Add Current File · Add Current Search and open them from the Saved Folders · Saved Files · Saved Searches lists. The first 5 saved folders and files also appear as buttons. Reorder, rename, set button names or delete them by kind in Manage Items. You can also add from the bookmark panel's right-click menu.
  • Hashtags: tag a file with right-click Edit Hashtags..., then pick tags by type and topic from the # button in the bookmark panel to search with #tag.
  • Automatic tagging (Settings 'Auto-assign file hashtags/keywords', off by default): after indexing, tags are added from the content (shown as ·#). The 🏷️ section of the Tools menu has Recalculate Tags · Review New Tag Candidates · Undo Last Automatic Tagging · Delete All Automatic Tags · Clean Up Missing File Entries.

16. Help · updates · components

  • Open this guide any time from Help → User Guide.
  • Version, copyright, license (GNU AGPL v3) and open-source notices are in Help → About.
  • Check for Updates: if a new version is available, it shows what changes in each version. Pressing [Update] downloads the file first, then closes all open PolyPDF windows and installs (if you cancel the download or it fails, nothing is closed). At the bottom of that window, Download Updates Automatically (on by default) fetches new versions in advance. Also Receive Beta (Test) Versions is always on before 1.0.
  • Tools → Register & Install → Install Components…: downloads ffmpeg for recording and the OCR engine (installed ✓ / not installed).
  • Tools → Register & Install → Install/Remove Virtual Printer…: when you print to the 'PolyPDF' printer from another program (PowerPoint, Word, Notepad …), it saves a PDF without a save dialog and opens it in PolyPDF. It saves next to the original file (or in the default save folder if the original can't be found) and adds (1), (2) if the name exists. Choose the save folder and black-and-white in that window. Available in the installed version only (not the portable one); it can also be installed during setup. Because it goes through printing, hyperlinks and bookmarks are not kept — use the program's own 'Save as PDF' if you need them. If your Windows default printer changes after printing, that is the Windows setting 'Let Windows manage my default printer'.
